# 十五　两个彭议乐（补密度）

合唱不是传记。能写进节题的名字必须有材料。

夏葵老师：原图标注老师，不计入学生。两个彭议乐：第一排一个，第二排一个，排数消歧。

寒塘渡鹤颖：朋友圈显示名。刘佑林确认是初一初二历史老师，真实姓名已忘，不再追踪。闫佩佩是另一位历史老师，有人物页。微信名不是鉴定，是她当时在我屏幕上的样子。录取通知书下面她评论过「恭喜恭喜」——那是后话，本章只让这个名字出现在名录的缝里。

孙思玥：朱学良 2026 年问卷，题干是月考出分谁最淡定、谁最慌。他说：「最淡定的只能说是你和孙思玥吧，我就比较慌。」月考，不是中考。他者之声后置，标 2026。不能据此写她的人格，只能写：有人把我和她放在同一句里。

脸：不认。

# 三十三　八月十九日（教师更替）

阳松：数学，班主任，高二高三。英语邓斌未换。换了的要按学期记，且疾病生育只作我的回忆：

- 生物：高二上欧庭良代课；贺文高二下起任教。我听说贺文高二上生育休养。
- 语文：代淑君短期；我听说因乳腺癌治疗离岗——个人回忆，不是校方结论。杨杰琼暂代。吴玲颖高二下起。
- 化学：李春香高二；我听说怀孕后不再任教。陈玉飞高三。
- 物理：袁如意高二；陈思懿高三。调动原因里的教学评价不写作成绩鉴定。

管理层时间线另起一行，不占课堂：杨革非高一党委书记、高二起校长；邓智刚高一校长、高二转长郡；向雄海高二调回任党委书记。刘智是教职工，合影里不要建成学生。

屏幕上的 1038 人是年级。换了，是教室里的人。

# 三十六　四百二十六（郑森的回声）

阳隽豪手稿仍是主线：同寝、鸟哥、舟哥、帆哥、耳塞、时政、RIO 似乎、省略的那个人、未写完的 WZW。

郑森不在 426 铺位表上。他出现在问卷里。他说自己拧巴的三例：有喜欢的女孩不敢加联系方式；想出绝妙方法不敢上台讲；闹矛盾想和好却从不主动说话。第一例不得用来解释我未添加赵问竹。两件都是「没加」。没加不是同一个没加。他授权可写打压式教育的那一巴掌，那是他的家，不并入我家。

互赠：我送他歼 35 模型；他送我《工程控制论》，并说是我主动要求的。书与模型的正式出场在第四十七、五十一章，不进第五十二章（马克龙）。本章只让模型在寝室闲谈里闪一下——若无同寝材料，闪在群里。

共同记忆他写过：上至世界局势，下到赵问竹和你。这是他的句子。赵问竹不在 426 的铺上。句子证明高二的闲谈会拐到第三部，不证明他看见过我的心。

# 三十八　老李

颜子杰：G2212，物理补习班，三角洲，王者。老李：高中补习班物理老师，用户称为物理启蒙，姓名「老李」。郑磊：补习班数学。补习班不是同班。两家相识他有两说：爸妈先认识；因陈亭妤（规范写法）是初中同学两家才认识。两说并置。

# 四十四　没有署名

《月华街 59 号回忆录》：126 页，12 题。美食、瞬间、老师、对自己说、猫与美景、后悔没做的、对朋友说、趣事、只有自己人才懂的梗——匿名合唱。我不把任何一条派给具体毕业生。门牌是那本书的标题，不是我家。二十张毕业合影是年级的。我只属于 G2204 然后 G2205。去向表写学校层级。猫可以作为一张照片被描写：在框里，有毛，有人伸手或不伸手。后悔那一题最靠近附录，但正文只引匿名的后悔，不把我没走过去的那几步写进别人的格子。
