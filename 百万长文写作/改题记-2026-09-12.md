# 改题记　2026-09-12

判定尺子只有一把（[[百万长文写作/规格]]「标题诗学」）：**题上只放还没有被解释的物、地、人、日期，或一句已确认的话。** 凡属下面五类的，一律换掉：

1. **功能词**：材料、名录、排次、名字们、栏目、关键词、逐件、档案版。
2. **提要词**：合影以外、从补习班来、月考之后、班长在场、杭州两日、青岛到北京、鞋带写进信。
3. **心理词／判断词**：赌气、借口、完整、沉静、聆听者、话多、两种人。
4. **技法名**：排比、并存、同类、相邻、少写、两说、第一说、第二说。
5. **能安在任何人头上的句子**：闪光、分开、还亮着、近距离、慢下来、普通日子、一个位置、还在不在。

## 一、改掉的八个章题

| 章 | 旧 | 新 | 理由 |
|---|---|---|---|
| 14 | 合影以外 | **框外** | 「以外」在替读者解释照片缺了谁。框是物 |
| 16 | 布置 | **家长会前** | 「布置」是空洞任务词。家长会前是时间与场合 |
| 19 | 闪光 | **闪光记录** | 「闪光」单独读是情绪；「闪光记录」是中学生手册上印着的栏目名 |
| 33 | 分开 | **八月十九日** | 任何人的分班都能叫「分开」。日期只属于这一次 |
| 38 | 从补习班来 | **老李** | 情节提要换成把那个地方钉住的人 |
| 42 | 还亮着 | **蛋糕** | 「还亮着」既空又与紧随其后的间章《灯还在》重复。2024-08-12 那块写着「今天你最帅」的蛋糕是实物，并接住[[百万长文写作/伏应]] #32 |
| 52 | 近距离 | **一笔** | 「近距离」是空词，还容易读成心理距离。签名那一笔是物，且接签名名单 |
| 58 | 慢下来 | **四十** | 「慢下来」是口号。四十份问卷是数字 |

**审过仍保留的**：第 9 章《不记得》（是向睿馨的原话，不是方法词）；第 24 章《多一丝》（王代良评语原文）；第 45 章《出分夜》（指向一个具体的夜晚，不是隐喻）；第 48 章《多一张》（他自己那句「如果多一张车票」的断片）。

## 二、改掉的两个辑题

| 辑 | 旧 | 新 | 理由 |
|---|---|---|---|
| 四 | 以外 | **牌子** | 章题已改为《框外》，辑题不再重复同一个否定式。牌子是十三章那两块实物 |
| 十一 | 距离 | **三楼西** | 「距离」是概念。三楼西是麓盛楼里能走到的地方 |

部题《空格》《亲爱的》《桌上》《西侧》《十七天》《保存》与序题《第十格》不动。

## 三、节题：换掉的主要类型与样例

全书 60 章的节题重抽了约一百三十处。按类型举例，逐章全文见[[百万长文写作/目录]]。

| 旧 | 新 | 换的是什么 |
|---|---|---|
| 序「像是十次」 | 十个栏目 | 删掉「像」这个解释，只留栏目数 |
| 序「一次」 | 一次写完 | 概念换成动作 |
| 2「他自己写的」 | 自我评价 | 换成表格上印着的字段名 |
| 3「相邻／少写」 | 党校／一九九八 | 两条教读者怎么读的指令，换成表上的机构与年份 |
| 6「借口」 | 睡前 | 心理词换成场合 |
| 7「影像」 | 一九八五 | 空词换成那台电视机的年份（[[百万长文写作/伏应]] #5） |
| 8「杭州两日／青岛到北京／机内时间」 | 西湖／首都／小屏上的钟 | 行程提要换成地名、父母的原话、相机屏幕 |
| 10「两种人／话多／聆听者／说法」 | 院子里／教室里／向睿馨／李顺贤／符雄辉 | 性格鉴定换成场所与三张具名的嘴（七律令第五条：评价必须有主人） |
| 11「班主任／栏目／一个下午」 | 李顺贤／签名／一次 | 职务换人名；「一个下午」是我们并不知道的次数，改成材料支持的「一次」 |
| 12「尚未开动」 | 离开益阳 | 解释换成动作 |
| 15「名录／名字们／排次」 | 删；两次 | 三个档案标签删到只剩事实：这个名字在名单上出现了两次 |
| 17「鞋带写进信／排比」 | 鞋带／十四岁 | 提要与技法名换成物与年龄 |
| 20「赌气」 | 志愿表 | 心理词换成那张表 |
| 21「两个人／不说话／还在不在」 | 启动仪式／签名／抽屉 | 三个空词换成场合、动作、那支笔现在可能在的地方 |
| 22「完整」 | 最后一个暑假 | 判断换成时间 |
| 23「月考之后／班长在场」 | 抽签／喻翰东／班长 | 情节提要换成装置与先出场的人（群像五条：错开出场） |
| 25「同类／并存」 | 胡彬／杯是他的 | 技法名换成人和那只杯子 |
| 26「前后／两周／不说」 | 前后桌／接水／实验器材／手拿开 | 补上材料里已有的三个动作，并把延宕点单独立成一节 |
| 27「数个／提前／取消」 | 不止一个／想不起颜色 | 情节链换成两条事实：福袋不止给了一个人；颜色和形状我想不起来 |
| 29「不懂／灰」 | 拍灰／不知道是谁 | 灰退回它该在的地方——讲台拍灰在正文，落下的灰在间章 |
| 30「光」 | 烟花 | 空词换成窗外那团东西。烟花与关灯从间章《灰》退回本章 |
| 31「没说话」 | 陈喜门口／最好看 | **本次最重要的一处增补**，见下节 |
| 32「同框／七月」 | 壹麓同行 | 与章题重复的「七月」删掉，换成那次活动的名字 |
| 34「未变／远远／目光」 | 走廊／食堂后门／不走近／一个人 | 三个空词换成空间与动作。「一个人」是「这幅画面里只有一个人在恋爱」的落点 |
| 35「我的／第一说／第二说／没有」 | 六个人／我记得的／没有第四张 | 版本说明书换成先说六个、再摊第四张（群像五条：先「那群人」再名字） |
| 36「似乎」 | 君子之交 | 不确定副词换成宋俊豪的原话 |
| 37「注意／题目」 | 相像／植物激素 | 「注意」换成他自己承认的动机；「题目」换成讲过的那道题 |
| 39「沉静／书写」 | 没有写到的 | 两个性格词换成那一页上的空白——她写了作业帮，没写烟花下的我 |
| 43「笑声」 | 笑工场 | 抽象声音换成那个地方 |
| 44「年级／去向」 | 月华街五十九号 | 校志标签换成校址 |
| 45「战役／等待／到来」 | 屏幕／分数／杨铨 | 隐喻和空词换成屏幕、数字、那晚在场的人 |
| 46「面试／强基」 | 各位考官下午好／抽两道／颜色 | 制度名词换成他记得的那句开场白和抽到的题干。**答法不写** |
| 47「日出」 | 缆车 | 通用风景换成宋俊豪那句「你先走了」发生的地方 |
| 48「关键词／隔着夏天」 | 如果多一张车票／仰望 | 方法词与来路不明的美词，换成两句他自己的话 |
| 51「逐件」 | 九件／两个红包 | 方法词换成数目 |
| 53「命名／没有替我」 | Heisenberg／未过 | 动作名词换成那个名字本身 |
| 55「两说／同组」 | 云南园／张天泽／刘桓彬 | 方法词换成地名与同组两个人的名字 |
| 56「开设／无视／言辞」 | 浏阳河／屋檐／那几句话 | 三个动作概括换成地点、建筑、那几句话 |
| 59「人物页／双链／平行」 | 来源／禁写／光标／我做过这些梦 | 知识库界面名词删到只剩屏幕上能看见的字 |
| 60「普通日子／不写进」 | 江安／左边／第三只杯 | 「普通日子」离「岁月」只有一步；「不写进」是方法句。换成地点、方位，和那只不在桌上的杯子 |
