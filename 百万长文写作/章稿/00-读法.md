# 章稿读法

**开写冻结。** 世界级文学对标续评 8.5／10，未达 9.00。见[[百万长文写作/对标续评-2026-09-12]]。未达闸门时，本夹只用于改已有核心稿与节题，不按五栏去写正文章。

本夹是开写前的施工图，不是定稿正文。达闸后每章固定五栏：

| 栏 | 作用 |
|---|---|
| 开 | 第一段完成：定声音、定契约、给向前的力。优先物件／中段切入。 |
| 收 | 停在动作、物件、未说完的话。删掉仍成立则删。 |
| 禁 | 高于文采。人物页、隐私、证据口径优先。 |
| 节 | 每一节只做一个动作。发生变化的节写慢。 |
| 核心草稿 | 400–800 字，可直接扩成正文的声音样本。已有长稿的章只给切口，不重写。 |

完整样稿另放 `核心稿/`。赵问竹线（23、26–31、33–34、39、41、48、57、59）与序、垂丝图、高考段、十八岁清单、西安——以[[百万长文写作/对照旧稿]]所列旧稿为底，本夹不另起炉灶。加密度与禁写见[[百万长文写作/人物]]。旧赵稿里的替她想可以留。仍砍：无材料天气、对读者授课的省略号排比。第一人称可推断、可替想，见[[项目管理/用户订正-2026-09-12-第一人称可推断可替想]]。30／51／57 不重复协议见人物页第二节。

开写另读[[百万长文写作/技法]]配额与[[百万长文写作/伏应]]该章配对。

扩写时：事实来自人物页与素材页。感官、对白、他人心理无材料则优先留空。连接句若整段都是接口，标 `【文学化重构·编号】` 并用 `> [!重构]` 包裹，**定稿不得去标**。该章开、收、结算物件仍立不住时，按[[百万长文写作/推演]]写有界推演：**先在[[百万长文写作/推演清单]]占编号，再落段**；段首 `【有界推演·编号】`，整段 `> [!推演]` 包裹。只补「我」的常规动作与被事实带住的接口，不新增事件、日期、关系、第三人内心。推演段落随正文走，润色不得删标。施工层按[[项目管理/用户订正-2026-09-11-长篇调用私密层|2026-09-11订正]]调用私密层叙事材料。手机号、证件编号、学籍号、密码仍不进草稿。
