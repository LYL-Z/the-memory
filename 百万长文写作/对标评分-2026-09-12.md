# 对标评分（2026-09-12）

封面书名后改为《刘佑林的19年回忆录》。本页分数评的是改定前的施工图，不因改名重评。

**综合 7.6／10。加权 7.5／10。未达 9.00。禁止开写六十章正文。**

本分评的是：现行目录、规格、人物／技法／伏应／意象／节奏，以及已经落在 `百万长文写作/核心稿/` 里的文字。不评尚未写出的 96 万字。杨绛、纳博科夫、埃尔诺的完成态仍不在同一赛道上被「超越」。

2026-09-11 终评的 **施工图 9.15／92** 作废为本分的替代。那一档把「可开写性」「全库覆盖」算进文学分，等于自己给自己发开工证。世界级对标不采施工便利。

9.00 的含义：读者不看说明书，目录与抽样章已经配得上被认真阅读的 memoir；长度是材料逼出来的，不是任务逼出来的；已有文字不再用「这本书的道德」完成章节。达到之前，只改施工图与已有核心稿，不新开正文章。

## 一、八维（对标天花板，不是内部清单）

| 维 | 天花板 | 现／10 | 为何不是 9 | 到 9 要什么 |
|---|---|---:|---|---|
| 目录诗学 | 《朝花夕拾》章题；《说吧，记忆》Mademoiselle O | 8.4 | 部名、章题大多只放物／地／人。节题仍泄漏说明：其实一次、后来证实的晴、不是我的、档案版、2026年那句、两套、并置、尽量不写、不是日记 | 节题微改，去掉判断与方法词；章题终锁不动 |
| 时间与物件时钟 | 地坛一地；骆驼队循环句；《岁月》照片切刀 | 8.2 | 五个入口有后果栏。间章设计对，十六则都还没写成。「后来」全书仍准 60 次。跳转仍容易靠时间词，不靠物件状态 | 间章先写成外视样本；「后来」再压；章稿开收必须写清物件怎么变 |
| 他者与限知 | 《背影》判断只打自己；《干校六记》小穿插 | 8.6 | 铁律、并置、人物页态度未知，强过克瑙斯高德。2026-09-12 替想合法，但无场次配额，桌上六章可能写成全知言情 | 替想按场，不按章灌；亲历的我仍不能先知 |
| 意象深度 | 《背影》一个部位；地坛一座园 | 7.3 | 深入口五件是对的。伏应 28 对偏电视剧。签名线七个名字是名单，不是意象 | 深 5 才准转义；其余只作交叉引用，写章时不准为了回收而写 |
| 必要长度 | 《干校六记》短；王鼎钧：细节是装修不是蓝图 | **6.6** | 《据说》《三张名单》《保存》各约 0.2 万已做完该章的活。规格仍把 96 万当工作值、章均 1.48 万。再扩就是注水。克瑙斯高德的长度来自日密度；本书没有日密度，却取了他的篇幅 | 96 万改为上限；工作值回到 84 万；快岛硬顶 0.8 万；核心稿已完成任务的章禁止为字数扩 |
| 七律令落地 | 八篇精读共同给出的七条 | 7.4 | 对标页已抄七条。章稿五栏没有「情感句有无情绪词／结尾是否总结／评价有没有主人」。已有稿末段常上课 | 七条变成每章开写前的闸，过不了不准扩 |
| 已有文字成色 | 名篇的句子标准，不是提纲标准 | 7.1 | 《据说》《三张名单》诚实，能停在物上。同一批稿把方法说成正文：「据说是这本书里最干净的词」「抄写员的职业道德」「整洁不是这本书的道德」。《保存》复读规格字段。旧赵稿省略号腔仍在过往参考里 | 抽样章先改到七律令全过，再谈六十章 |
| 读者不看说明书 | 打开《干校六记》不必先读作者的写作手册 | 7.0 | 目录已经接近一本书。抽样正文仍在教读者怎么读这本书。推演黄标是伦理成就，也是间离；间离必须靠场面撑住，不能靠说明书撑住 | 方法句只准出现在序、第 5、第 58–60；其余章用场面履约 |

算术平均 **7.6**。加权（必要长度 18%、已有文字 16%、他者 12%、意象 12%、七律令 12%、时间 10%、目录 10%、说明书 10%）**7.5**。

最低维是必要长度。最高维是他者与限知。世界级长篇 memoir 的失败，多半死在长度，不死在证据。

## 二、作品对作品

## 三、已有核心稿：七律令抽样

抽样三章，因为它们已经是本夹里最像「章」的文字。旧赵稿另记一刀。

### 《据说》（第 5 章，约 1800 字）

| 律令 | 过／否 | 依据 |
|---|---|---|
| 触发物具体可反复 | 过 | 信、问卷、照片 |
| 跳转靠物件状态 | 过 | 借来的三件东西轮流出场 |
| 最重的句子无情绪词 | 半过 | 「那一天不是我的」干净；「最干净的词之一」「这一章是履约」在上课 |
| 人物靠动作或平淡台词 | 过 | 母亲问卷原句 |
| 评价有主人 | 过 | 母亲说晴；十四岁的我说冷 |
| 错误认知是资产 | 过 | 信上的冷与问卷的晴并放 |
| 结尾停在具体东西 | 半过 | 「那一天不是我的」后仍接推演：穿衣洗脸识字。章在 1800 字处已经该停 |

文学判断：作为短章，7.8。作为将扩到 1.5 万的章，5.5——没有那么多出生事实可写。

### 《三张名单》（第 35 章，约 2100 字）

| 律令 | 过／否 | 依据 |
|---|---|---|
| 触发物 | 过 | 三行记录平放 |
| 物件跳转 | 过 | 第一行／第二行／修改句 |
| 无情绪词 | 否 | 「整洁不是这本书的道德」「真实不必先安静下来再进入文学」「制度常常比青春可靠」 |
| 动作立人 | 过 | 「你是个 0」只作公开声音，不盖章 |
| 评价有主人 | 过 | 各张嘴分开 |
| 错误认知 | 过 | 坐稳的名单不是证据 |
| 结尾停在物 | 半过 | 「空座位还空着」好；前面已对读者说教 |

文学判断：7.4。活在 2100 字里已经做完。再扩只能重复「我不终裁」。

### 《保存》（第 60 章，约 1900 字）

| 律令 | 过／否 | 依据 |
|---|---|---|
| 触发物 | 过 | 保存键、桌子、茶可以不在 |
| 物件跳转 | 半过 | 闪回是清单，不是状态变化 |
| 无情绪词 | 否 | 「格子不是坟墓」「性格是最容易说谎的章题」 |
| 动作立人 | 半过 | 按键、拿开；中间复读关系字段 |
| 评价有主人 | 过 | 字段不升级 |
| 错误认知 | 不适用 | 当下章 |
| 结尾停在物 | 半过 | 「光标还在闪」好；闪回段是目录复读 |

文学判断：7.0。结尾方向对，正文仍是规格说明书。

### 过往赵稿（不在本夹重写，迁入前先过闸）

`长篇创作/` 里「省略号还在」「停在了省略号上」是对读者授课的隐喻。西安稿用「我在这本书的第三卷里」把结构说明写进场面。这些文字可以当材料，不能当声音。迁入前必须砍掉卷名、省略号腔、对读者解释这本书。

## 四、必要长度：为什么这是最低分

世界级 memoir 的长度来自材料，不来自任务书。

| 作品 | 大约体量 | 长度怎么来的 |
|---|---|---|
| 《朝花夕拾》 | 短篇集 | 一事一篇，写完即停 |
| 《干校六记》 | 薄册 | 一记一动作 |
| 《说吧，记忆》 | 约十五章 | 癖好与物件，不按学年灌 |
| 《我与地坛》 | 一篇七节 | 一地反复 |
| 《我的奋斗》 | 六卷极长 | 日复一日的密度 |
| 《补写的手册》现行 | 工作值 96 万，章均约 1.48 万 | 任务书先写下篇幅 |

《据说》《三张名单》《保存》已经证明：本库最硬的几章，用 0.2 万可以做完。把它们扩到 1.5 万，不是向纳博科夫看齐，是向注水看齐。

克瑙斯高德配得起那个长度，因为他写刷牙、排队、孩子哭，写到时间自己在纸上过完。本书禁止用模板补天气气味，又没有逐日日记。取他的篇幅、守自己的禁令，逻辑打架。

因此：96 万是天花板，不是成绩单。84 万是防注水意识，也应是工作值。快的岛硬顶 0.8 万。核心稿已经完成开收与结算物件的章，禁止为了靠近章均而扩。

## 五、闸门

同时满足以前，**不准开写第 1–60 章正文**（含把核心稿扩成正文章）：

1. 本页八维均不低于 8.5，算术综合不低于 **9.00**。
2. 抽样四章——第 5《据说》、第 35《三张名单》、第 26 或第 31（赵线一章）、第 60《保存》——按七律令改到全过，且不再出现「这本书的道德／抄写员／读者若问」。
3. 规格写明：96 万＝上限；工作值 84 万；快岛 ≤ 0.8 万；已完成任务的章不扩。
4. 伏应分深浅：深 5 才转义；其余交叉引用不得反向编造。
5. 至少写成一则间章外视样本（照片／票根／截图，不写心情说明）。

未满足时只允许：改本夹施工图、改已有核心稿、改节题说明腔、补材料。不允许：新开正文章、按 1.48 万去填。

旧终评「开写顺序」整节作废，改以本页为准。

## 六、本分不自动上涨

同日若把第 3、4 条写入规格与伏应，那是通向 9 的作业，**不在本页加分**。加分只在下一次对标：重读改过的抽样章、改过的节题、写成的间章样本之后，另开日期页。
