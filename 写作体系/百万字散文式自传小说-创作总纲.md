# 百万字散文式自传小说：创作总纲

## 一、作品定义

作品以非虚构材料为基础。事实构成骨架，散文提供质地，小说技法负责节奏与场景组织。所谓“三体融合”，不是把事实、抒情和虚构混在一起，而是让三者各守边界：

- **事实为骨架**：关键事件、人物关系、时间节点、原话和结果必须来自知识库。
- **散文为肌理**：通过意象、节奏、感官、留白和回望形成语言质感。
- **小说为血肉**：采用场景化、伏笔、回环、对照和章节张力，但不能因此发明关键情节。

## 二、四项底层原则

### 1. 三体融合

拒绝编年史式流水账，也拒绝以“好看”为由篡改真实。素材没有提供的具体天气、气味、物件位置、动作、对白和心理，不能直接补成事实。确需尝试时，应在草稿中标注为 `[文学化重构]`，并等待确认。

叙述者自己的心理也不能任意补写。可写的内容分三类：当时留下的文字或明确回忆；现在对当时的解释；明确标注的不确定推测。第三人的心理只能通过其可观察行为、原话或本人自述呈现。

### 2. 回望叙述与限知

默认叙述声音是**成年后回望的我**（2026-08-28规格）：用现在的口吻讲当时的事，承载回忆与惋惜，不把全书改成儿童正在说话。

认知边界仍然分开：

- **当时能知道的**：动作、所见、当时的误解。回望者叙述时不得让当年的自己提前拥有后来的信息。当时的误解属于限知或自欺，不是作者对读者隐瞒事实。详见[[写作体系/技法库/不可靠叙述|不可靠叙述]]。
- **现在才明白的**：明确标为回望。不审判，也不洗白。

不采用童年沉浸式主叙述，不频繁切换人称或旁观视角。亲历与回望不是两个主持人抢话筒，而是一个回望者转述自己当年有限的看见。详则见[[写作体系/长篇创作规格-2026-08-28-颜子杰建议与用户确认|长篇创作规格]]。

### 3. 散而不散

时间线是明线，精神成长是暗线。全书按人生阶段连贯推进，不做成独立短篇集。风物与日常可以作点缀章，但须停在时间河里。

长篇可设置三至五个反复出现的核心意象。意象必须从既有材料中统计和筛选，不能为了文学效果硬造。每次重现应承担新的含义，避免只作装饰。

### 4. 真实优先

不设置主角光环。素材中的怯懦、虚荣、自私、笨拙、误判和逃避应得到保留。其他人物也不能被压缩成恩人、反派、白月光或工具人。每个判断都要问：这是一次行为、某人的评价，还是跨时间稳定存在的特征？

## 三、五卷式长篇框架

以下框架是内部抽屉，不是必须对外的目录。2026-08-28规格要求**时间顺序主线、约84万字、高中合计20—30万字**。高中的学业、班级与情感写在同一时段里，不再把第二、第三卷写成两遍高中。各抽屉字数随素材密度调整。

### 第一卷：童年与底色

关注家庭空间、早期学校、亲属、发小、旧物与最初的秩序感。重点不是“可爱的童年”，而是后来人格的底色如何出现。

### 第二卷：青春与阵痛

覆盖初中与高中。写成绩、班级、师长、同窗、竞争、友谊、羞耻、渴望与第一次复杂的人际判断。避免把青春写成单一的怀旧滤镜。

### 第三卷：爱与迷失

处理被吸引、误解、期待、沉默、靠近与错位。所有关系判断都要区分事实、当事人感受和后来的解释。未获对方确认的内心不得代写。

### 第四卷：困境与重建

关注离开熟悉环境后的失衡、大学适应、学业选择、失败、身份重组与新的关系网络。重建不是励志口号，而是一系列具体而缓慢的行动。

### 第五卷：和解与当下

回看家庭、学校、友谊和自我。和解不等于原谅一切，也不要求所有问题得到答案。结尾应允许未完成、犹疑和继续生活同时存在。

## 四、章节节奏

- 每三至五篇高密度情感或事件章节，可安排一篇风物、物件或日常随笔。
- 高强度章节之间要有“呼吸页”，但呼吸页仍应推进人物理解或意象变化。
- 单篇原则上只承担一个主要情感转折。多条线索并置时，应有清晰的收束点。
- 章节结尾优先使用动作、物件、声音或未说完的话，不默认添加感悟总结。

## 五、意象系统的建立方法

1. 从现有笔记中统计反复出现的房间、道路、植物、天气、旧物、声音和食物。
2. 记录每个意象首次出现的事实场景，避免脱离原始语境。
3. 检查它是否跨越至少两个阶段，并能承载意义变化。
4. 确定主意象三至五个，次级意象若干。
5. 为每次出现记录“旧义—新义”，防止重复抒情。

## 六、真实与艺术化的分界

| 内容 | 默认处理 |
|---|---|
| 已确认时间、地点、人物、事件 | 可直接写入事实层 |
| 当事人原话 | 保留来源；未见原件时写“据总结/回忆” |
| 他人评价 | 标明评价者与场景，不上升为测评结论 |
| 自己当时的心理 | 仅在有文字或明确回忆支持时写实 |
| 现在的反思 | 明确属于“回望的我” |
| 他人心理、动机 | 不代写；只能写观察与推测边界 |
| 缺失的感官细节 | 不用模板填充；待补采或标记重构 |
| 合成场景、压缩时间 | 必须在工作稿注明，不能伪装成逐字纪实 |

## 七、普遍情感的落点

私人经验可以通向遗憾、愧疚、渴望被爱、自我怀疑、离别和成长，但不必每篇都上升为“人类共同命题”。普遍性应从具体细节自然长出。若一篇文章以私人画面结束更准确，就不强行升华。

## 八、禁止事项

- 禁用“时光荏苒”“岁月如梭”“回首往事”等模板化开场和转折。
- 不用排比证明文采，不用金句代替叙事。
- 不为圆满而改变事实，不为冲突而夸大关系。
- 不把一次互动写成稳定亲密，不把沉默写成默认同意。
- 不把回忆中的模糊处伪装成高清现场。
- 不闯入他人的内心，不借文学化替他人作道德判决。
- 不直接模仿具体作家的独特文风，只学习可迁移的结构与技法。

## 九、完成标准

一章合格，不在于辞藻密度，而在于：事实可追溯，视角不越界，人物有灰度，细节有私人来源，结构有回响，语言没有模板味，删掉结尾说理后仍能成立。
