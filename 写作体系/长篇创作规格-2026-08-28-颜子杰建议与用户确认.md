# 长篇创作规格（2026-08-28）

本页把颜子杰提出、用户采纳的全书规格写成可执行口径。它管“怎么组织这本书”，不管“能写什么”。事实、隐私和人物页始终优先。67号书目只提供技法，不提供目录。

> [!warning] 与旧稿的关系
> 旧总提纲按约90万至105万字、五卷主题重叠、双声部频繁交错来估。本规格改为：**目标约84万字**；**时间顺序为唯一主线**；**叙述声音以成年回望为主**；**不做成《朝花夕拾》式独立短篇集**。五卷名称可继续当内部抽屉，但高中不再拆成两卷各写一遍。

## 一、篇幅与时间权重

| 项目 | 规格 |
|---|---|
| 全书目标 | 约 **84万字** |
| 高中 | 叙事核心，约 **20万至30万字**（学业、班级、情感、校外补习与出行都合在这一时段里写，不另开等长的情感专卷） |
| 覆盖周期 | 祖辈／童年早期、幼儿园、小学、初中、高中、大学 |

高中“核心”不等于课堂讲义。颜子杰反对的是**堆砌知识点**。军训、分班、同组、关键人物、校外补习、研学与出行仍可详写。校园日常（食堂、跑操、作业）作点缀，用来给关键节点垫一层生活，不写成校志。

## 二、结构与线索

1. **主线**：时间顺序。按人生阶段推进；每个故事挂在可指认的人生节点上。
2. **可穿插**：补叙、插叙、故地重游时的今昔对照。回忆录里“现在走回旧地、看见什么没了”是通行手法，但对照物必须是刘佑林自己去过的地方，不能借用颜子杰举例里的石鼓广场等未核地点。
3. **支线：平行时空**。不进入事实层。每个关键节点故事之后，可附一则“若当时另选”的分支；全书末再写一个最理想化的总平行时空。已有赵问竹线推演见[[高中/素材/文学化推演/平行宇宙与梦境素材索引|平行宇宙索引]]。各节点的具体分歧尚未敲定，见[[长篇创作/平行时空支线设计草案-2026-08-28|平行时空支线草案]]。
4. **全书形态**：连贯长篇。人物篇、风物可在时间河里作为章节，但**不用独立标题短篇集**的总结构。《朝花夕拾》只学单章内部的“一事一人引出岁月”，不学成书方式。

## 三、视角

- 固定第一人称“我”＝刘佑林。
- **成年回望**为默认叙述声音：带着回忆与惋惜，而不是整段改用儿童口吻讲完全书。
- **不采用童年沉浸式主叙述**，也**不频繁切换**成第二人称、旁观者或多声部，以免断裂。这是颜子杰明确给出的理由。
- 知识库与AGENTS仍要求：**回望者不得让当年的自己提前知道后来的信息**。写童年所见，用回望者转述当时能懂的感知即可，不必另开一个“小佑林正在说话”的声部。

通行回忆录讨论里，回望叙述者同时踩在“当时”与“现在”两处；本规格选择**现在的声音讲当时的事**，用故地、旧物触发跳转，而不是两套“我”轮流主持。

## 四、选材与表达

- 选对人生思想、性格产生影响的人与事；成长与情感变化是核心。
- 童年空间：益阳城区、老家、外出游玩等，以已有材料和待采为准，不编造菜品、影片与誓词。
- **以小见大**：通过具体人、具体选择看见长大；“折射时代”只能落在高考日程、分班、疫情校园、校服等已核制度与风俗上，不把同学写成时代标本。
- 工作主题假设：**在爱里成长**——童年接收过的照料与善意，如何成为后来共情与行动的底色。这是颜子杰提出、用户采纳的情感逻辑。**没有材料就留空**，不得为了闭环补造教练包容、摊贩消失等他人的记忆。

## 五、67号书目在新规格下怎么用

| 作品 | 仍可用 | 不再用于 |
|---|---|---|
| 高尔基三部曲 | 按阶段换舞台、写实密度 | 控诉型社会标本 |
| 萧红《呼兰河传》 | 景物—日常—命运叠在同一空间；淡笔写重事 | 儿童口吻主持全书 |
| 巴金《家》 | 群像用不同选择区分 | 礼教大家庭戏、把亲人原型化 |
| 《务虚笔记》 | 个别回望章的意象拼贴 | 替代时间主线 |
| 《我与地坛》 | 故地圆心、克制的亲情 | 残疾与生死命题、排比四季 |
| 汪曾祺 | 日常点缀的烟火 | 把全书写成无冲突小品 |
| 《边城》 | 环境为关系服务、留白 | 湘西牧歌滤镜 |
| 《背影》 | 一个动作撑亲情 | 套用背影句式 |
| 《朝花夕拾》 | 章内一事一人 | 独立短篇+标题的全书结构 |
| 《城南旧事》 | 限知与离别分寸 | 用同学命运强行折射时代 |

## 六、颜子杰在书中的位置

他可以同时是：高二下补习班相识的朋友、游戏与来访的参与者、以及向刘佑林提出这套写作框架的人。后一项是**交流中的功能**，不等于他是全书的共同作者，也不把“亦师亦友／同频者”写成双方共同确认的关系称号。人物侧写见[[高中/素材/人物资料/颜子杰/颜子杰创作建议与人物侧写-2026-08-28|颜子杰创作建议与人物侧写]]。
