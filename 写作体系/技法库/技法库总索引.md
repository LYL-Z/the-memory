# 技法库总索引

本库穷尽整理"怎么写"的技法：叙事方式、记叙顺序、表达方式、表现手法、修辞手法、描写手法、对话方法，以及散文、小说、诗词、非虚构自传各文体的写法，长篇结构方案，和文学性/爽文性/细节性/准确性的平衡。它是[[写作体系/写作体系索引|写作体系]]的"表达层"工具箱，为百万字散文式自传小说的写作提供技法基础。

> [!important] 三条铁律（先于一切技法）
> 1. 技法只属于**表达层**：可改变呈现方式，不改变[[写作体系/创作总纲-百万字散文式自传小说|创作总纲]]规定的事实、视角与隐私边界。
> 2. **只学可迁移的高层技法**，不模仿具体作家的独特文风（见[[写作体系/风格参考/作家作品参考谱系|作家作品参考谱系]]）。
> 3. 冲突时**事实证据、隐私规则、具体人物页始终优先**；宁可留白，不以文采、爽感或细节填补事实缺口。

## 七、调用流程（写作前必读）

1. **先事实，后技法**：从人物页、事件页、时间线、原始材料建立"事实包"（人物/事件/地点/物件/原话/来源状态/隐私等级）。
2. **定视角与顺序**：确定第一人称双视角的可知边界，选记叙顺序（见二）。
3. **选结构**：单篇选一个主结构 + 至多一个辅助结构（见[[写作体系/技法库/叙事结构与语言工具|叙事结构与语言工具]]）；长篇对位结构桩（见[[写作体系/技法库/长篇结构与写作方案|长篇结构与写作方案]]）。
4. **落语言**：以描写代抒情、白描为主、炼字为核，按需调用表现/修辞手法与对话技法。
5. **配质量**：用四维自检（准确/细节/文学/可读）过一遍。
6. **落修改**：完稿后按[[写作体系/技法库/修改与润色方法|修改与润色方法]]走——冷藏 → 结构/人物/逐句三遍 → **事实审** → 删 10%。
7. **完稿审计**：事实、视角、隐私、语言、结构五审（见[[写作体系/写作体系索引|写作体系索引]]）。

> [!warning] 涉及他人在世者时，第 0 步
> 落笔前先读[[写作体系/技法库/非虚构自传的法律与伦理边界|非虚构自传的法律与伦理边界]]。**真实不是隐私之诉的抗辩；改名不等于安全。**
> 朗读一遍[[写作体系/技法库/句子节奏与声音|句子节奏与声音]]自检，若某段读起来"特别顺"，要警惕它是否只是空洞的节奏。
