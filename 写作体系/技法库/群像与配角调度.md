# 群像与配角调度

> [!important] 本项目的特殊前提
> 知识库已有二十个班毕业名录、大量合影、小组与课代表记录。这是**极罕见的群像材料密度**，也是**极大的滥用风险**：名录和合影只证明"同框／同班／同时间段"，不证明关系、性格、亲疏。本页所有技法都在这一前提下使用。

## 一、群像写作的根本难题

读者一次只能记住有限的人。问题从来不是"人太多"，而是**"没有给读者记住的把手"**。

三个层次的失败：
1. 同时抛出一堆名字 → 读者一个也没接住。
2. 每个人给一段生平 → 变成花名册。
3. 让所有人同时说话 → 分不清谁是谁。

## 二、五条调度原则

### 1. 错开出场（Stagger）
不要一次把一群人交完。先给两三个，剩下的在后续的重复接触中自然分离出来。

**关键认识**：读者对一群人的第一印象，不必是"这是五个人"，可以是"这是一个我还没融入的群体"。后者比任何个人简历都更贴近真实经验——你转学时确实先认识"那群人"，然后才认识张三李四。

### 2. 用一个结构性装置轮流聚焦
找一个本来就存在的机制，让每个人依次进入焦点，而不是为每个角色单独造一场戏。

可用的装置：
- **固定作息**：食堂、宿舍熄灯后、早读、跑操、晚自习课间。
- **固定轮换**：值日表、座位轮换、小组重组、课代表交接。
- **重复事件**：每次月考后、每次分班、每次放假返校。

这样，"让某人被看见"就成了故事机制的副产品，而不是作者的检查清单。

### 3. 每组给一个发言人
一群人中让一个承担主要对话，其他人有反应、有动作，但不必人人长篇。这既减少混乱，也更像真实——真实的群体里确实有人替大家说话。

### 4. 用对比快速切割
差异承担识别功能。一个人前倾，一个人冷笑，一个人沉默——同一个场景里三种姿态，读者立刻分得开。不需要给每个人写独白。

### 5. 通过叙述者的需要过滤（最被低估的一条）
**不要中立地描写每个新人物，要通过"当时的我"恰好缺少／害怕／渴望什么来写他。**

同样是描写一个同学，"他成绩很好"是客观信息；"他能在讲台上把一道题讲三遍而不急"是通过当时那个害怕被点名的我来写的。**后者一份力气做了两件事：既立住了对方，也立住了当时的我。**

### 补充：不必人人有名
只出现一次、不承担功能的角色，可以只用身份指代（"隔壁班那个高个子""收作业的"）。名字是稀缺资源，留给有分量的人。

## 三、多人对话的调度

- 人越多，**动作节拍（action beat）越重要**。对话标签（他说）只解决归属，动作节拍同时解决归属和空间感。
- 每个人在场都要有其**当下的利害关系**。若某人在一场戏里无事可做、无话可说、也无反应，那他不该在这场戏里。
- 例外：婚礼、毕业合影、开学典礼这类**大规模事件**，配角的在场本身就是内容——此时"只是站在那里"是有意义的。这正是合影素材可以合法使用的方式。

## 自传写作调用

1. **班级群像章节**：以学校的固定作息为装置（早读—课间—午休—晚自习—熄灯），每一段聚焦一到两个人，不写全班点名。
2. **毕业名录的使用**：名录用于**核对与召回**（姓名写法、班级、排次、时间），不用于**批量虚构**。不得因为名录上有某人而为其补写性格或事件。
3. **合影的使用**：只支持"同框／同班／同时间"的事实。不得据外貌推断性格、情绪、关系（见 `AGENTS.md` 相关约束）。
4. **小组／课代表记录**：只能支持"阶段性接触条件"，不能直接写成关系亲密。
5. **过滤视角是本项目的主力技法**。写同学时，先问一句："当时的我，在他身上看到的是自己缺的什么？"把答案写进去，比写外貌有效得多。
6. **教师群像**：按学期记录（任课与更替已有专门页面），避免把毕业合影的教职工名单直接等同于全程任课名单。

## 风险与禁忌

- **严禁按名录批量生成人物性格**。名录有 N 个人，不等于可以写 N 段性格速写。
- **严禁据合影外貌推断个人**（`AGENTS.md` 明文禁止）。
- **严禁把"同组"写成"亲密"**，把"同班"写成"交情"。
- **严禁为群像效果编造集体事件**（如不存在的班级活动、集体对话）。
- **涉及在世者的群像描写，每个人都要过隐私关**。群像不等于可以放松个人标准；恰恰相反，被一笔带过的人最容易受到漫不经心的伤害。
- **不得用"某某等同学"的方式模糊掉真实在场者**，也不得反过来把不在场者写进场景。
- 名字是事实，不是道具。每个人的姓名写法以知识库校勘结果为准（见 `AGENTS.md` 姓名校勘条目）。
