# 物件叙事：让物替人说话（实操卡）

> **定位**：全书最适配"沉默与表达"主线的技术。人不肯说的话，由物替他说——而物不会撒谎，也最容易出错，这个"出错"就是文学的入口。

## 一、物件的四级使用

| 级 | 用法 | 例（库内物） | 效果 |
|---|---|---|---|
| L1 记录 | 物只是出现 | 1985 年全村第一台电视机 | 建立时代坐标 |
| L2 定格 | 物承载一个场景 | 那台电视机买回来的第二天，全家坐成一排 | 场景有了焦点 |
| L3 转义 | 物替人说感情 | 他没说"对不起"，他把遥控器放在我手边 | 情感不用嘴说 |
| L4 结构 | 物贯穿全书 | 报告册：一卷出现→五卷合拢 | 主题物化 |

## 二、本书的"结构级物"（已具备素材）

1. **小学报告册**（补写的手册）——书名级。
2. **车票/火车**——离聚线。
3. **答案册**——替代表达线。
4. **茶**——父亲的安静。
5. **2022 年的那封信**——第一次"把家写下来"。

## 三、物件叙事五律

1. **物必须有出处**：进了正文的物，必须能在 [[长篇创作/我的物件史与文化消费年表-2026-09-06|物件史年表]] 找到对应行；找不到就先补年表（补年表必须有库内证据）。
2. **物不解释自己**：写"那台电视机是全村第一台"就够了，不要写"它象征着父亲深沉的爱"——象征让读者自己长出来。
3. **一件物只用一种转义**：报告册就是"被书写的我"，不要某章又变成"制度压抑"。义变必须登记进 [[长篇创作/意象台账-2026-09-06|意象台账]]，一次一个。
4. **物的易朽要写**：物会丢、会洗坏（工程训练护照被洗衣机洗）、会被吃掉（凉包子）——**易朽性是感情的容器**。
5. **别人的物只写别人**：董佳好的谷子/汉服、王麒睿的驾照、夏思成的排球——这些是**他们的**物，出现时只能从刘佑林的旁观视角写，不得抢用。

## 四、本场域的"物的密度"建议

| 场景类型 | 物件数/章 |
|---|--:|
| 家庭日常 | 3–5 |
| 校园 | 2–4 |
| 出行 | 4–6（车票、箱子、相机、鞋） |
| 电器/网络场景 | 1–2 |
| 抒情独章 | 0–1（越少越好） |

## 五、自检

- [ ] 本章的物都在物件史年表里吗？
- [ ] 有没有一句"象征着…"？（有 → 删，改写成物的动作）
- [ ] 有没有让别人的物替别人说话、却写成了"我"的感受？
- [ ] 物的易朽写到了吗？
