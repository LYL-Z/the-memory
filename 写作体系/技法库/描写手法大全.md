# 描写手法大全

描写是"用语言把人、事、景、物具体画出来，给读者身临其境之感"。它是本书"展示而非告知"的主力（见[[写作体系/技法库/叙事结构与语言工具|叙事结构与语言工具]]"感官替代抒情"）。描写属于表达层：可以让已确认的场景更可感，**不能补出材料里没有的天气、气味、动作、对白与心理**。

## 一、按对象分

### 1. 人物描写
- **外貌描写（肖像描写）**：容貌、衣着、神情、体型、姿态。忌面面俱到，抓最能显性格的一两处特征。
- **语言描写**：个性化的话（详见[[写作体系/技法库/对话与人物语言写作|对话与人物语言写作]]）。
- **动作描写（行动描写）**：以个性化动作揭示性格。动词是灵魂。
- **心理描写**：内心感受、意向、思索、思想斗争。
- **神态描写**：面部表情，侧面透露心理。

> [!warning] 自传的人物描写红线
> 第三人的**心理**只能通过其可观察的言行、原话或本人自述呈现，不得代写。"我"的心理只在有当时文字或明确回忆支持时写实；否则标 `[文学化重构]`。合影、名录只支持姓名/班级/站位，**不得据面部外貌推断性格**（见[[高中/G2204/自传叙事规则|自传叙事规则]]）。

### 2. 环境描写
- **自然环境描写（景物描写）**：地点、季节、气候、时间、场景。作用：烘托心情、渲染气氛、推动情节、点明/突出中心、交代背景。
- **社会环境描写**：人物活动的处所、背景、时代氛围、人际关系总和。作用：交代时代与社会根源（如《孔乙己》开篇的酒店与世态）。是本书"时代锚定"的落点（见[[写作体系/技法库/叙事结构与语言工具|叙事结构与语言工具]]"时代锚定"）。

### 3. 场面描写
对多人参加的活动/劳动/战斗/娱乐场景的综合描写，反映群体面貌。常用**点面结合**：既写整体（面），又聚焦典型个体（点）。

### 4. 细节描写
对表现人物或推动情节有特殊作用的细小环节（动作、神情、物件、环境）的细致刻画。**细节是描写的地基**：一个真实的小动作胜过一堆形容词。

## 二、按角度分

### 5. 正面描写（直接描写）
直接刻画对象的外貌、心理、行动、语言。

### 6. 侧面描写（间接描写）
通过他人反应、评价或环境烘托，间接表现对象，收"烘云托月"之效。
- **以人衬人**：借旁人的话与反应表现某人。
- **以环境衬人/衬事**：借场所、氛围、社会状况烘托。
正侧结合往往比单一正面更立体（如写美，既写其貌，也写观者的失神）。

## 三、按详略/笔法分

### 7. 白描
用最简练、质朴的文字，不加烘托渲染，寥寥几笔勾出鲜明形象。鲁迅归纳其要诀："有真意，去粉饰，少做作，勿卖弄。"实质上"用叙述的方式进行描写"。**是本书首选笔法**：与私人化细节、留白天然契合。

### 8. 细描（工笔）
精雕细刻、浓墨重彩、全面具体。适合关键人物/关键时刻的定格。用量要省，否则臃肿。

白描与细描不是对立，而是配比：全篇以白描为底，个别高光处用工笔定格。

## 四、按状态/视点分（景物描写专用）

### 9. 动静描写
静态描写（位置、颜色、形状、纹理）+ 动态描写（变化、动作），以动写静、以静衬动、动静结合。

### 10. 观察点的组织
- **定点描写**：立足固定观察点，由上到下/由远到近/由整体到局部地铺展。
- **移步换景（步移法）**：随观察者移动，景随人换（游记常用）。
- **随时推移**：同一景物随时间（晨—昏、四季）变化而变化。

## 五、五感描写（沉浸感的核心）

调动**视觉、听觉、嗅觉、味觉、触觉**，让读者用身体而非逻辑体验场景。
- 操作口诀：**删掉概括环境/情绪的抽象形容词，替换为人物当下的五感真实感知**。
- 选择性使用：一个场景选二三种最特别的感官即可，五种全写会臃肿。
- 例：不写"食阁很热闹"，写"海南鸡饭的姜蓉香、隔壁碗碟的碰撞、后背黏着的汗"。

## 六、"展示而非告知"（Show, don't tell）

- **告知（tell）**：抽象概括——"她很害怕。"
- **展示（show）**：给证据——"她的手掌沁出冷汗，心撞着胸腔。"
- 判据：把结论摆给读者，还是把证据摆给读者、让读者自己得出结论？后者才有沉浸与共情。
- **但两者都需要**：展示用于情感高点与关键转折（放慢、细写）；告知用于过场、桥接、压缩时间（提速）。全篇皆展示会拖沓。

## 七、描写选用（对照表）

| 目标 | 首选描写 |
|---|---|
| 让人物一眼立住 | 抓特征的外貌 + 一个个性化动作 |
| 传达难言的情绪 | 神态 + 五感 + 留白（不点破） |
| 还原一个场所 | 社会/自然环境 + 定点或移步 + 二三感官 |
| 群体事件 | 场面描写 + 点面结合 |
| 一生的重量压在一物上 | 细节 + 白描 + 象征 |
| 关键时刻定格 | 细描（工笔）少量使用 |

## 八、自传写作调用

1. **私人化细节优先**：只用属于这段人生的细节（具体教室、校服、楼道、旧家具、书页批语、方言、游戏、天气记录），拒绝"花香""夕阳很美"这类可套给任何人的句子（见[[写作体系/技法库/叙事结构与语言工具|叙事结构与语言工具]]"私人化细节"）。
2. **缺失的感官不补模板**：材料没写的天气/气味/动作，列为待采问题或标 `[文学化重构]`，不用通用模板填空。
3. **以白描为主、留白收束**：情绪最高处减少解释，用动作、物件、空间变化让读者完成判断。
4. **环境描写承担时代锚定**：用真实的年代设备、校服、考试制度、街道来定位时间，不凭大概年代拼贴。

## 九、风险与禁忌

- 用抽象形容词代替感官证据（"很美""很难过"）。
- 五感堆砌、面面俱到，失去焦点。
- 据合影外貌推断性格；代写他人心理。
- 为"电影感"补造未被材料支持的动作、声音、心理，或用"镜头/慢镜头/配乐"等术语替代实际描写。
- 工笔滥用致臃肿；白描空泛致寡淡（淡不等于空，每一笔都要与人物或地方相关）。
