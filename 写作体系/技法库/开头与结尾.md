# 开头与结尾

## 一、开头要完成的三件事

开头不是"第一句话要漂亮"，而是要在最短篇幅里完成：

1. **定声音**：读者通过第一段判断叙述者是什么样的人——他在什么距离上看这件事。
2. **定契约**：这是回忆还是现场？是解释还是呈现？读者需要在第一段知道该怎么读。
3. **给一个向前的力**：一个未完成、一个错位、一个待回答的问题。

## 二、六种开头方式（按自传适用度排序）

| 方式 | 说明 | 自传适用度 |
|---|---|---|
| **中段切入**（in medias res） | 从动作中途开始，前因后置 | 高 |
| **物件／空间切入** | 从一个真实存在的物或地点起笔 | 高 |
| **一句话定调** | 首句即给出全篇的情感坐标 | 高 |
| **悬念／疑问** | 提出一个读者想知道答案的问题 | 中（不可造悬疑） |
| **场景定格** | 一个静止画面，随后时间开始流动 | 中 |
| **框架装置** | 用"我如今再想起……"框住全篇 | 中（易套路化） |

### 值得反复研究的三个中文开头

- 朱自清《背影》：**"我与父亲不相见已二年余了，我最不能忘记的是他的背影。"**——一句话同时给出时间距离、情感焦点和全书悬念（为什么是背影）。
- 鲁迅《从百草园到三味书屋》：**"我家的后面有一个很大的园，相传叫作百草园……但那时却是我的乐园。"**——先给地点，再给"现在／那时"的对照，孩子的价值判断压在句末。
- 林海音《冬阳·童年·骆驼队》：**"骆驼队来了，停在我家的门前。"**——不解释，先给画面。

三者的共同点：**首句即给出时间与情感的双坐标**，且**没有一个字是形容性的**。

## 三、结尾的四条路径

1. **回到开端（圆形结尾）**：回到开头的意象、地点或动作，但叙述者的理解已经不同。**这是自传最常用的结尾**，因为自传的本质就是"重临"。
   - 林海音《冬阳·童年·骆驼队》结尾："我默默地想，慢慢地写，又看见冬阳下的骆驼队走过来……童年重临于我的心头。"——开篇的骆驼队回来了，但这一次是"写"出来的。
2. **停在一个动作或画面**：不解释，不总结。
   - 迟子建《灯祭》结尾："这是我送给父亲的第一盏灯，那灯守着他，虽灭犹燃。"——十一个字收束全篇的生死。
3. **停在一段关系的未决处**：承认没有结论。
   - 史铁生《我与地坛》末句："宇宙以其不息的欲望将一个歌舞炼为永恒。这欲望有怎样一个人间的姓名，大可忽略不计。"——先扩张到宇宙，再落回"姓名"，把个人故事交给沉默。
4. **留一个向后的回声**：末句让读者回头重读开头。

## 四种必须避免的收尾

| 坏收尾 | 症状 |
|---|---|
| 总结式 | "这就是我的母亲，一个平凡而伟大的女性。"——把已写出的东西再说一遍 |
| 升华式 | 强行把个人经历拔到普遍真理 |
| 报告式 | "总之""由此可见""通过这件事我明白了" |
| 抖机灵式 | 末句突然转向俏皮，卸掉前文全部重量 |

## 自传写作调用

1. **人物篇开头**：优先"一句话定调 + 物件切入"。避免"我有一个同学，他叫……"这类介绍式开头。
2. **事件章节开头**：优先中段切入。从事件最紧张的中途起笔，把前因压到第二段。
3. **卷首与卷尾**：建议使用圆形结构，但**回到的必须是同一个真实意象**，且该意象在全卷中至少出现过两次以上（见[[写作体系/技法库/叙事结构与语言工具|叙事结构与语言工具]]"意象锚点"的适用条件）。
4. **结尾自检三问**：
   - 删掉最后一段，文章是否依然成立？（若成立，说明末段是冗余的总结）
   - 末句里有没有形容词？（自传的末句靠名词和动词承重）
   - 末句有没有替读者下结论？

## 风险与禁忌

- **不得为了首尾呼应而编造物件动作或天气变化**。圆形结尾的"回"必须是事实层面的回，不是修辞层面的回。
- **不得为了开头的抓人而制造不存在的悬念**。自传的开头可以平淡，不可以虚假。
- **已确认事实不得使用"开放式结尾"制造双解**（见[[写作体系/技法库/不可靠叙述|不可靠叙述]]）。回忆可以有盲区，结论不能有两套。
- **涉及他人在世者的章节**，结尾不得做道德判决。停在事实，不停在裁决。
- 结尾的沉默必须建立在**前文已交代清楚**的基础上。留白不是逃避交代。
