# 烟花与《婚礼进行曲》

高一下学期，班里拿我和赵问竹打趣，已经成了日常。起头是一本作业：那天中午我从讲台上取回自己的数学作业，想顺手把本组的也都带回去，结果只找到她那一本。王麒皓看见封面上的名字，问我："你在帮赵问竹拿作业呀，你是不是喜欢她？"我记得自己笑了笑，没有回答，把作业放到了她桌上。

没有回答，在十五岁的班级里等于回答。这件事当天下午就进了525寝室，后来又长出许多版本。有人叫我"主席"，后来改口叫"竹席"。我从没有认领过这些玩笑，也从没有反驳过。现在想来，反驳需要开口，认领也需要开口，而我最不擅长的恰好是开口。玩笑就这样替我把话传了出去——传得比我自己想清楚的还要快。

烟花是在一个月考前的晚自习出现的。

课间，等我从卷子里抬起头，窗边已经站满了人。橘子洲的方向在放烟花，隔着大半个城市，隔着玻璃。赵问竹也在窗边。

我说不清自己是怎么走过去的。我只记得我站定的时候，是在她身后。

我至今不记得那晚烟花的颜色。按理说那是全教室唯一的风景，人人都在看它。可是留在我记忆里的只有一个背影的轮廓、教室玻璃上浮着的一层反光，还有我自己越来越响的心跳。烟花是很亮的东西，我却像没有看见它。后来我想，那晚窗边站着两种人：看烟花的，和看看烟花的人的。

然后灯灭了。

是吴明博，拉了几个男生，把教室的灯关了。黑下来的一瞬间，讲台上的一体机响起了音乐。我听出来是《婚礼进行曲》。

全教室都在笑。烟花还在窗外一阵一阵地亮，音乐把黑暗填得满满的。那首曲子我在电视里听过很多遍，它响起来的时候，总有两个人并排站着，被所有目光围在中间。现在它为我响。我站在她身后，脸红得发烫，脑子里只剩一个念头。

我借口去厕所，离开了教室。

走廊里很安静，安静得能听见身后的音乐和笑声隔着门变闷。蒋明追出来拉我，要我回去。我没有回去。我在教室外面站着，站过了整个课间，站到第二节晚自习的铃声响了，才走回自己的座位。

那晚剩下的时间，赵问竹比平时沉默。我觉得她好像也脸红了。

——这两样，都只是我看见的。或者更诚实一点说，是我愿意看见的。她那晚一个字也没有对我说，我也一个字没有对她说。

小时候在益阳，烟花是过年的东西。它属于所有人，在院子里，在天台上，想看多久看多久，看完了还有饺子。我从没想过烟花也可以是这样的：只放给一段几分钟的黑暗，你站在离一个人最近的地方，却在它最亮的时候转身出门。

多年以后我仍然不知道，她那晚站在窗边，看见的是烟花，是同学的闹剧，还是别的什么。这件事没有材料，没有旁证，也没有第二个讲述者。我唯一能够确定的，只有我自己的那部分——

烟花往上升，我往外走。

《婚礼进行曲》响到第几小节我离开的，我不记得了。我只记得走廊的灯很亮，比教室亮，比烟花亮。一个借口上厕所的人站在那样亮的地方，哪儿也没去，等一段音乐结束，等一场烟花散场，等铃声把一切变回晚自习。

铃声真的会把一切变回晚自习。这是我在十五岁那年就验证过的物理。
