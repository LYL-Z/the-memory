# 《补写的手册》：编年四部总提纲

> [!important] 唯一现行施工总提纲
> 旧五卷总提纲与五份「章节设计-第X卷」改档案。开写、改稿、核心稿嵌入，一律以本页及四部章节设计为准。

## 一、作品是什么

一部以非虚构材料为骨架的散文式自传长篇。事实来自知识库；散文管质地；小说技法管节奏与场景，**不发明关键情节**。

2026-09-12 夜封面书名定为 **《刘佑林的19年回忆录》**。曾用工作书名《补写的手册》仍指小学报告册被一次性补写这件事：十九岁回头，为前十九年补写，格子里装的是真的，写下的日期是现在。其余旧候选（《默默》《答案放在你桌上》《一鸣惊人》《江安的水送我归家》）可作部题或章题。本页仍是过往参考。

叙述声音：2026 年正在整理材料的大学生。年轻、距离近、许多事尚无结论，写进方法，不假装暮年智慧。回望者不得让当年的自己提前知道后来的信息。

## 二、章法（编年脊骨 + 二十辑物件 + 舞台换场）

舞台仍按人生阶段换场，但读者目录的主单元是 **二十辑**，不是四个部名。部从四扩为六，只为符合写作体系「单卷十五至二十万字」：高中拆成 G2204／G2205 两部顺时针写一遍，大学拆成「握车票／交答案」两部。不是回到五卷主题重叠。

完整节题、间章、章法标签见 [[长篇创作/全书细目-六部二十辑-章与节]]。

1. **编年脊骨**：益阳 → 金海 → 月华街上（G2204）→ 月华街下（G2205）→ 江安上 → 江安下。
2. **二十辑**：每辑一个核心动作、一件结算物件（荷马；当代长篇「情感靠物件结算」）。
3. **十六飞鸟间章**：模型C，高强度之后一页间奏；不另开空风景卷。
4. **章内 6–8 节**：场景／概述／延宕切换（五种叙事速度）。

暗线仍是 **沉默与表达**。工作主题假设仍是 **在爱里成长**。两条暗线并存。

结构桩不变（催化＝提前录取，第一道门＝入麓山，中点＝分班，第二道门＝高考结束）。分班现为第四部开篇。

## 六、铁律（写作时高于章题好看）

1. 赵问竹：高中同班；我单方爱慕；她的态度未知。沉默就是沉默。西安与未添加联系方式只并置。
2. 董佳好：同学、阶段性同组、长期聊天朋友。相像只属于我的回顾性动机。保密内容不写。
3. 杨铨：不写收入、现工作学校、自媒体。刘拓段落须先给本人看。宋俊豪不写情感。曾子沣少写其上大学以前。阳隽豪评价克制，并记住他不支持过多使用 AI。
4. 合影、名录、同组不等于亲密。六人组三说、桃园「不记得」、RIO 学期口径——并存，不终裁。
5. 精确住址、成绩、健康、证件号、第三方财富不入正文。
6. 章末优先动作、物件、声音、未说完的话。删掉结尾说理后，画面须仍能成立。
7. 草稿保留 `[已确认]` `[单方回忆]` `[来源视角]` `[待核]` `[文学化重构]` `[回望解释]`。
