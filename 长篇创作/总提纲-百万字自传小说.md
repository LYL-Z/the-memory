# 百万字自传小说：总提纲

本提纲把创作总纲落到现有素材上。2026-08-28起，体量、主线、视角以[[写作体系/长篇创作规格-2026-08-28-颜子杰建议与用户确认|长篇创作规格]]为准：约84万字，时间顺序主线，高中合计20—30万，成年回望，平行时空仅支线。五卷仍是内部抽屉。未采材料标【待采】，不虚构。67号书目只提供技法。

## 一、书名候选（待定）

1. **《补写的手册》**——小学报告册系李顺贤在升学节点为前五年补写，十栏皆有其签名却非逐学期同期写就。这本书做的是同一件事：在十九岁回头补写前十九年。方法即隐喻。
2. **《默默》**——报告册十栏中反复出现的词；"沉默—表达"正是全书暗线。
3. **《答案放在你桌上》**——他一生的表达方式：不说，就把答案、资料、礼物放在对方桌上。
4. **《一鸣惊人》**（反讽兼期待）——赵问竹书面评价的末句。
5. **《江安的水送我归家》**——2025年国庆朋友圈原句，含"离家—归家"的水与路。

## 二、总主题与双线

**明线**：时间线。益阳—长沙—成都（—新加坡），2007—2026。

**暗线（精神主线，仍有效）**：**沉默与表达**。一个被十栏评语反复要求开口的孩子，如何一步步获得（并仍在学习）表达：

**工作主题假设（2026-08-28，颜子杰提出、用户采纳）**：**在爱里成长**。须从已有照料与善意的事实长出，不得为闭环补造童年。两条暗线可以并存，不互相取消。

- 替代性表达：做题、讲题、"作业帮"、把答案册放在她桌上；
- 被推动的表达：起哄、真心话大冒险里小声的"我喜欢你"；
- 书面表达：2022年写给父母的信、朋友圈长文、世界杯叙事；
- 公共表达：课堂到讲座、新加坡演讲第一、开发应用、个人网站；
- 最终的表达：把一生结构化为知识库，写成这本书。

全书本身就是暗线的终点——**这本书是那个不敢举手的孩子交出的最长一次发言**。

**普遍情感落点**（自然长出，不硬贴）：被爱与照料、羞怯与错过、离家与归家、代际的沉默付出、把热爱做成事情的少年心气。

## 五、视角与声部策略

- 叙述声音：**成年回望**（2026年正在整理材料的大学生）。年轻、距离近、许多事尚无结论，这些要写进方法，而不是假装暮年智慧。
- 当时的看见由回望者转述，保留幼稚与误判；不另开儿童主持人，不少换视角。
- 写他人一律见证人位置。赵问竹的沉默写成沉默。
- 故地重游可切入现在，但地点须是刘佑林自己的。

## 六、材料密度与诚实边界

- 素材重心在2022—2026（高中、大学、聊天、朋友圈148则），童年与初中较薄。**卷一、卷二前半将保持较多【待采】占位**，宁可薄写、不可虚构。
- 待采清单随各卷章节设计给出；采得新材料后先入知识库，再回填章节。
- 已知的重大待核张力（写作时只并置、不解释）：2026-08-12刘佑林自述"至今没有添加赵问竹的联系方式"，与2026年五一母亲、刘佑林、赵问竹同游西安并同看《寒战1994》并存。两条都是用户确认材料，其间的联系方式与成行经过【待采】。
- 隐私红线：私密层字段（住址、成绩、健康、第三方隐私、董佳好保密内容等）不进入任何章节正文；董佳好线只用脱敏骨架；"前任"等第三方不建节点、不画像。

## 七、章节通用规格

- 单章3000—5000字，单章只承担一个主要情感转折；每3—5章设一篇风物/物件/日常"呼吸章"。
- 章末优先以动作、物件、声音、未说完的话收束；不加感悟总结。
- 草稿保留 `[已确认]` `[单方回忆]` `[待核]` `[文学化重构]` 标记（见[[写作体系/写作体系索引|写作体系索引]]），定稿前执行事实/视角/隐私/语言/结构五审。

## 十、写作推进路线

1. 先写材料最厚的卷三、卷四样章群，建立语感与声部。
2. 卷一、卷二按待采清单向用户补采（家庭口述、初中细节、益阳风物）。
3. 每完成一辑，执行五审并回填知识库交叉链接。
4. 全书维护三份台账：意象台账（旧义—新义）、伏应台账、时间线一致性表（以知识库为准）。
5. 正式分章前先补[[长篇创作/素材缺口与待采清单-2026-08-28|待采清单]]中的学段事件，避免空壳大纲。
6. 平行时空支线单列，见[[长篇创作/平行时空支线设计草案-2026-08-28|草案]]，不写入事实层。
