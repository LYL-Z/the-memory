# 第二部　金海·一封写给父母的信

> [!important] 本部长什么样
> 这是离家的第一座学校。高中尚未开始，赵问竹不在此部展开。本部的情感核心不是恋爱，是**十四岁第一次用书面向父母清点被爱**。名录里的人是合唱，不是每人一传。符雄辉不在合影里——把「合影看不见的人」写成方法。

**部首引语**（≤180字）：

长沙不是风景。长沙是校名改了一次的那所中学，是1907班的合影，是李文静说：给父母写一封信。我把信写完的时候，并不知道自己会把这封信保存到十九岁，也不知道后来会把它当作童年的说明书来读。

> [!important] 2026-09-11 晚间加密
> 本部对应 **辑四至辑六**。节题以 [[长篇创作/全书细目-六部二十辑-章与节]] 为准（6–8 节）。

**字数**：10章 × 约 1.2 万 = 12 万。高一报到划给第三部。

## 第13章　湘郡金海，雨花区金海　约1.2万字

**节**
1. 十一二岁决定去长沙
2. 校名沿革：同一所学校，两块牌子
3. 1907班
4. 往返：家在益阳，人在雨花（路线待采则写待采）
5. 《金海之歌》：集体的声音里有没有我的声音

**核心草稿**：录取与进城只写制度与决定，不写鸡汤。校名沿革必须准确，避免读者以为换了学校。寄宿与否、周末交通若仍待采，正文写「我现在无法准确画出那条路」，禁止用通用「想家的夜晚」模板。校歌可引用已确认歌词，不编造我当时是否唱出声。

**素材**：初中学校背景 · 金海名录 · 校歌材料
**证据**：入学与班号已确认；心情、交通【待采】。

## 第14章　合影里没有的班主任　约1.2万字

**节**
1. 初一：符雄辉，班主任兼政治
2. 评语里的「较安静、偏内向」
3. 他为什么不在毕业合影里（不猜原因）
4. 怀孕、离职、现任单位：只保留用户提供的未核信息边界——**正文不写**
5. 2025年6月9日他会在评论区出现（伏笔，一笔）

**核心草稿**：符雄辉身份来自用户提供，不得写成合影可见事实。评语续写「默默」的迁移，不诊断人格。涉及生育、离职、现单位的信息按规则不进普通长文。章末只轻轻指向高考日评论「静待佳音」——那是三年后的事，此处不剧透情节，只让名字留下一个将来会回来的位置。

**素材**：[[初中/2022届/人物/教师/符雄辉]] · 成长闪光记录
**证据**：身份与评语；合影缺席是事实；原因不写。

## 第15章　1907：小林子、两个彭议乐、最淡定的两个人　约1.3万字

**节**
1. 一张合影能证明什么，不能证明什么
2. 夏葵老师站在「第一排学生」行
3. 两个彭议乐：第一排与第二排
4. 名字们：孙思玥、李悦铭、刘哲昊、朱学良、邹鸿霖
5. 历史课：闫佩佩，以及那个被叫作「寒塘渡鹤颖」的人
6. 问卷里的「最淡定」——他者之声后置，标明2026

**核心草稿**：合影纪律：只支持学校、届别、班级、排次、姓名、标注身份。夏葵是教师。两个彭议乐暂按两名同名学生，用排数消歧，不判为名单重复。同学只写有据点的交集；无事件则保持名字。朱学良等问卷材料以「2026年他说」补叙，不倒灌成初中现场全知。不根据面部识别性格。

**素材**：[[初中/2022届/金海中学2022届1907班-毕业名录]] · 初中人物页 · 问卷回收
**证据**：名录已确认；交往事件大多【待采】。

## 第16章　家长会前，李文静说写信　约1.1万字

**节**
1. 三则署名评语里的班主任
2. 某次家长会前的作业
3. 教室里的布置（场面待采则不编）
4. 我开始写「亲爱的」
5. 这封信后来成了童年的说明书

**核心草稿**：李文静是要求写信的人。家长会日期、是否朗读、父母当时反应均未提供——不补。本章只写「布置」与「我坐下来写」。信的内容分给下两章，避免一章撑破。

**素材**：[[初中/2022届/人物/教师/李文静]] · 信叙事整理（背景）
**证据**：布置已确认；课堂流程【待采】。

## 第17章　信：给妈妈　约1.2万字

**节**
1. 照料清单再读一遍
2. 系鞋带写进了信里
3. 识字与幼儿园
4. 十四岁第一次清点被爱
5. 典故与排比：少年修辞的温度和错误

**核心草稿**：正文调用脱敏叙事整理，不粘贴私密逐字原文，除非用户当场要求核对。出生与婴儿期内容标明家庭转述。回望者可以温柔指出混用的典故，但不嘲笑写信的孩子。章末停在「写给妈妈的那几页被叠好」——动作，不是感悟。

**素材**：[[初中/2022届/素材/家庭书信/2022-01-25写给父母的信-叙事整理]]
**证据**：信已确认；四张手稿原图不入普通正文。

## 第18章　信：给爸爸　约1.2万字

**节**
1. 长期在外的叙述
2. 回到益阳
3. 伯牙子期：他当时这样比喻
4. 积累的感情
5. 回望：人事档案不是这封信

**核心草稿**：父亲工作调动、长期在外、回到益阳——必须标为「刘佑林2022年信中叙述」，不能改写为人事档案。与第一部第7章互参，不重复铺陈茶与棋，只让十四岁的理解出场。章末：信写完了，家长会怎么用这封信，我不知道。

**素材**：同上 · [[家庭/人物/父亲]]
**证据**：信中叙述层。

## 第19章　闪光记录与我记不清的日常　约1.1万字

**节**
1. 中学生手册里的肯定与要求
2. 2020：疫情进校园的部分（有个人材料才细写）
3. 2021：双减作为背景音
4. 数学优势延续（脱敏趋势）
5. 我记得的少，档案记得的多

**核心草稿**：疫情与双减只写有个人材料支撑处，缺则概写公共背景，禁止新闻腔排比。学业只写趋势。本章是金海日常的诚实空洞：闪光记录在，具体的午饭、晚自习、一次吵架大多待采。把「记不清」写清楚，比编一段典型初中更接近一流。

**素材**：成长闪光记录 · 时代背景页
**证据**：评语已确认；个人疫情叙事【待采】。

## 第20章　中考之夏　约1.2万字

**节**
1. 2022年6月
2. 查分与志愿（过程待采则写结果节点）
3. 麓山：当时对「四大名校」语境的理解
4. 俗称与官方名称
5. 通知到达的那一天（细节待采）

**核心草稿**：中考是第二道门。分数不入正文。对麓山的理解标为当时认知。不写「命运的转折点」类句。若查分场面无材料，就写节点：考了，出分了，确认了志愿。

**素材**：中考至入学时间线 · 学校背景
**证据**：结果已确认；考场与家庭反应【待采】。

## 第21章　清溪村：莫言、刘慈欣、一支笔　约1.2万字

**节**
1. 2022年8月，新时代山乡巨变启动仪式
2. 见到两个人
3. 要到的签名
4. 签名不是故事的高潮，是我开始收集「做成的人」
5. 笔还在（物件下落待核则写待核）

**核心草稿**：签名意象首置。场面按朋友圈#2022-08已确认事实写，不补造与莫言、刘慈欣的对话。回望可轻点：后来余隋怀、科希克、大兵、Joshua Tan 会接着出现——此处最多一笔，不剧透大学。禁止写成「文学少年得到加持」。

**素材**：朋友圈索引 2022-08
**证据**：见面与签名已确认；逐句对话无。

## 第22章　最后一个完整住在益阳的暑假　约1.1万字

**节**
1. 2022-07-23 岳阳
2. 2022-08-02 张家界黄龙洞：父子
3. 益阳的房间还是原来的样子（空间待采则不编）
4. 行李
5. 九月还没到

**核心草稿**：这是家作为每日现场的最后一整段暑假（此后高中寄宿，家不再是每个夜晚的默认坐标）。出行有相册锚点，日常无则留白。章末停在未关上的箱子或未写完的开学须知——待采允许更具体的物件。高一报到留给第三部第23章，本部不抢「525」。

**素材**：时间线出行 · 【待采】暑假日常
**证据**：两次出行已确认；「完整住在益阳」为结构判断，须在正文标为回望。
