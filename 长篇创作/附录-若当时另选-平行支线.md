# 附录　若当时另选

> [!warning] 封面必须印在附录首页
> **以下不是已发生的事。** 人物行为、对白、心理、关系结果均为文学设定。不得回写人物页，不得用来判断真实人物的态度。不虚构未成年性行为；涉及共同居住须写清监护、独立房间与生活边界。有力量的分支同时写出选择、代价与后果，不能只完成愿望。

本附录对应 2026-08-28 规格的支线，而不进入编年正文。正文里的梦只以「我做过这些梦」的身份一笔带过；展开的「若当时」集中在此处，避免读者把反事实读成回忆。

## A1　若当时走过去　约1.5万字

对应正文第30–31章：烟花夜、同桌示意「勇敢一点」、我借口离开。

**节**
1. 第二节铃响之前
2. 走到窗边（反事实）
3. 可能说出口的那一句
4. 班级作为现场：起哄不会自动消失
5. 代价：一旦开口，游戏与真心之间的保护层没有了
6. 仍不知道她会怎样——附录也不得替她答应

**核心草稿**：只改我的脚步。她的反应保持未知或写成多种可能并置，不写成唯一浪漫结局。禁止用此章「证明」现实里她在等待。

## A2　招生咨询会　约1.5万字

对应已提交构想：高校招生咨询会重逢。

**节**
1. 真实锚点：分班、两所大学的后来事实只作对照物
2. 咨询台前的重逢（反事实）
3. 谈话只能使用双方现实里可能拥有的信息
4. 代价：重逢不等于时间退回高一
5. 离开咨询会现场

**核心草稿**：调用真实物件（笔记本、答案、浙大／川大作为后来的学校）必须重新标记为虚构情节中的道具。不让现实西安「证实」本支线。

## A3　同返益阳　约1.5万字

对应构想：大学返校后同赴益阳。

**节**
1. 车票：多一张的那张被贴上名字（反事实）
2. 益阳不是风景明信片
3. 家的边界：不写未授权的家庭内部
4. 代价：两个家庭、两套时间表
5. 返程

**核心草稿**：共同居住旧禁令有效。益阳空间脱敏。不把此行写成现实西安的「正确版本」。

书末总支线。理想化不等于无代价。各节点未点选前，本章保持「设计中的空白」亦可——空白本身符合本书伦理。

**节**
1. 若所有关键节点都另选
2. 走读／合租构想的边界（监护与房间）
3. 学业与开口同时发生时失去的东西

5. 合上附录，回到第60章的当下

**核心草稿**：收束必须把读者送回事实层。最后一句指向正在写的那本书，而不是指向「她终于」。用户点选前，第2–4节可只列问题清单。
