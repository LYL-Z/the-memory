# 第一部　益阳·纸上的童年

> [!important] 本部长什么样
> 材料薄，就写成薄。本部门槛不是「写出一个完整童年」，而是诚实呈现：**我对童年的第一手记忆很少，纸比人多。** 族谱、推荐表、四张证件、一封十四岁写的信、十栏补写评语、发小后来的问卷——这些才是舞台。缺角保持缺角。精确住址不入正文。

**部首引语**（回望的我，≤180字，定稿可改）：

我后来才发现，益阳这一段几乎全是别人替我写下的。族谱里有一个位置，推荐表里有一个男人，证件夹里有一个尚未成为母亲的女人，报告册里有一个「默默」的学生。我要做的不是把格子填满，而是承认：格子先于我存在。

> [!important] 2026-09-11 晚间加密
> 读者目录的主单元改为 **二十辑**（外加十六飞鸟间章）。部扩为六，仅拆舞台体量，不改章号 1–60。
> **节题以 [[长篇创作/全书细目-六部二十辑-章与节]] 的 6–8 节为准**；本页早期 3–5 节表作底稿，冲突时听细目。

**字数分配**：12章 × 约 1.1–1.3 万字 = 14 万。章内 6–8 节。辑间插入飞鸟间章，不另开空风景章。

**本部长线**：被书写的我（手册）／试卷的确定性／茶／月亮（信中比喻，不作风景模板）／火车尚未开动。

## 序　补写的手册（不计本部字数；全书方法章）

- **目标字数**：1.0 万（已有试写，见[[长篇创作/试写/序章-补写的手册]]）
- **节**
  1. 十个格子，一个签名
  2. 评语写于升学，不是写于学期末
  3. 这本书也是一次补写
  4. 我能确定的，和我不能替别人确定的
- **核心草稿**：从李顺贤一次性补写的十栏评语进入全书方法：格子里装的是真的，写下的日期是现在。交代四层分离（事实／他人评价／回望解释／文学化重构）。不以金句收束，停在「打开下一页纸」。
- **素材**：报告册评语页；写作体系总纲。**不写**私密原表分数与住址。

## 第1章　垂丝图上的位置　约1.2万字

**节**
1. 彭城堂与四页世系
2. 「光积庆时雍肇睦亲太」：我停在哪一辈
3. 兼祧：肇雄无后，父亲出抚
4. 未见过的祖父：睦造卒于我出生前十二年
5. 纸比祠堂近

**核心草稿**：开篇不写「我出生在一个怎样的家庭」。先让读者看见垂丝图——横线、竖线、一个尚未被我亲手填写的空位。兼祧只写制度事实：肇雄（1926—1948）早逝无后，父亲出抚兼祧；不演绎宗法制心情。睦造（1953—1995）只写谱载与「我从未见过他」。章末动作：手指停在自己那一格，没有把格子涂满。

## 第2章　推荐表里的男人　约1.2万字

**节**
1. 湖南到新疆：一张表上的迁徙
2. 会计电算化，大专
3. 体育委员、生活委员、劳动委员
4. 「他当时如此描述自己」
5. 公寓职务那一行看不清

**核心草稿**：父亲刘必胜进入正文的方式不是「我的父亲如何伟大」，而是一份毕业就业推荐表。写迁徙节点、专业层次、学生职务。自我评价必须保持「表格自述」身份，不改写成人格鉴定。字迹不清的公寓职务保留待核，把「看不清」写成场面。不写迁移原因、经济状况、对「我」的影响——材料没有。

**素材**：[[家庭/素材/父亲毕业就业推荐表-脱敏摘要]] · [[家庭/人物/父亲]]
**证据**：脱敏摘要可调用；原表其余字段在私密层。

## 第4章　谭妈　约1.1万字

**节**

2. 选幼儿园的人
3. 月亮、火、风：少年比喻原样保留
4. 黑夜里照着我的那两个人
5. 技能比誓言可靠

**核心草稿**：照料清单来自2022年信，须标明「十四岁的我这样回忆」。月亮、火、风是信中原意象，允许进入，但回望者不得用成年修辞把它们重新镀金。不把母亲写成圣母。结尾动作：系好一只鞋——若记忆无此特写，则写「信里有系鞋带，我现在系鞋带时会想起那一行字」，避免伪造现场。

## 第7章　茶、棋盘，以及后来才亲密的父亲　约1.3万字

**节**
1. 手机里的人
2. 2016年10月：他回到市区

4. 大红袍、正山小种、铁观音

## 第9章　桃园：记得的人与不记得的人　约1.2万字

**节**
1. 大哥、二弟、三妹
2. 三位母亲彼此认识

## 第10章　课堂里的默默，院子里的发神经　约1.1万字

**节**
1. 对陌生人偏内向
2. 熟悉之后会有奇怪而逗笑人的言行
3. 「发神经」只是熟人打趣
4. 生日只差一天：她这么说
5. 两套观察，不要焊成一种人格

**核心草稿**：向睿馨的观察与李顺贤评语中的「沉默」并置，作为情境差异，不写成心理诊断，也不用发小材料「推翻」老师评语。王培森、曹卓雅若出场，只写有据点的交集；曹卓雅三锚点「不记得」、王培森对某条同桌记忆「印象里没有」须保留。不写成绩排名。

**素材**：向睿馨人物页 · 小学同学问卷
**证据**：发小视角；「生日差一天」不反推刘佑林精确生日。

## 本部待采（写作前向用户）

1. 奶奶日常、称呼习惯、任何一件具体的事。
2. 益阳家中空间（房间功能即可，不要门牌）。
3. 小学课堂一件真事：举手、值日、与王培森或曹卓雅。
4. 父亲回城后第一次共同活动。
5. 三结义现场：若三人同聚补采，以当场为准；在此之前两说并存。
6. 戴教练乒乓球课的时段。
7. 提前录取：谁送考、通知如何到达。
