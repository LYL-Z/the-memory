# 属性字典

本页规定 The Memory 常用 YAML 属性的规范类型。同名属性在全库必须保持同一类型，否则 Obsidian 属性面板和 Dataview 会按全局推断摇摆。

属性写在笔记顶部的 YAML 区。含内部链接的属性值须加引号。参见 [Obsidian Properties](https://obsidian.md/help/Editing%20and%20formatting/Properties)。

Vault 内 `.obsidian/types.json` 与本字典一致。新增笔记应直接按本表填写，不要再使用空键、`是/否` 字符串或未加引号的 `YYYY-MM-DD`。

## 列表（multitext）

单值也写成单元素列表。

| 键 | 示例 | 说明 |
|---|---|---|
| `用途` | `[Obsidian知识库, 百万字散文式自传小说]` | 页面用途，可多项 |
| `人物` | `[刘佑林]` 或 `[刘佑林, 赵问竹]` | 本页涉及的人物 |
| `作品` | `[荷马史诗]` | 文学或影视作品 |
| `证据类型` | `[毕业合影]` | 材料类型 |
| `tags` | 使用 Obsidian 标签语法 | 系统标签 |
| `aliases` | `[]` | 别名 |
| `cssclasses` | `[longform]` | 页面样式类 |

## 文本（text）

空值写成 `""`，不要留空键。看起来像日期、但不能保证全是 `YYYY-MM-DD` 的字段一律当文本。

| 键 | 示例 | 说明 |
|---|---|---|
| `姓名` | `"刘佑林"` 或 `""` | 人物页姓名 |
| `学校` | `长沙麓山国际实验学校` | 单所学校用文本 |
| `学段` | `高中` | 单学段用文本 |
| `班级` | `G2204` 或 `""` | |
| `性别` | `""` | 模板可空 |
| `班级分层` | `""` | |
| `选科` | `""` | |
| `合影排数` | `""` | |
| `任教阶段` | `""` | |
| `学科或职务` | `""` | |
| `班主任任期` | `""` | |
| `主题` | `文化与审美` | 单主题用文本；多项用中文分号 |
| `时间范围` | `2024-01至2026-08` | 闭区间描述，不是 Date 对象 |
| `适用范围` | `全库` | |
| `材料批次` | `"2026-08-21"` | 批次标识；须加引号，避免被解析成日期 |
| `date` | `"2026-08-15"` 或 `待核` | 本库该键含“待核”，不能设为 date 类型 |
| `资料截止` | `"2026-08-12"` 或带说明的句子 | 含注释时不是纯日期 |
| `审计日期` / `收录日期` / `更新日期` | `"2026-08-21"` | 文本日期 |
| `分类标签` | `【成长叙事】` | 顶层域标签，单值；取值：人物谱系／成长叙事／写作技法／风格参考／长篇创作／背景资料／审美档案／私密层／项目运维 |
| `材料层` | `人物` | 二级形态（人物／名录／素材／审计／索引／模板／协议），与 `类型` 互补，不冲突 |
| `文件编号` | `RZ-成长叙事-0001` | 元数据页眉编号，全库唯一；前缀 RZ-<域缩写>-<顺序号> |

> **`分类标签` 与 `类型` 的分工**：`分类标签` 是**顶层域标签（单值、9 选 1）**，回答"这份文件属于哪个大域"；`类型` 是**二级形态标签**（如 `写作技法库`/`卷级章节设计`/`学校档案`），回答"它是什么形态"。二者共存、互不替代。新增文件须同时填 `分类标签` 与既有 `类型`（若有）。

## 复选框（checkbox）

只使用 YAML 布尔值 `true` / `false`，不要写“是／否／已入库／未入库”。

| 键 | 真值含义 | 假值含义 |
|---|---|---|
| `原图入库` | 原图已在 Vault 内 | 仅有文字索引或原图未提供 |
| `允许公开导出` | 本页可进入公开导出 | 默认不导出 |
| `禁止公开导出` | 明确禁止导出 | 未禁止 |
