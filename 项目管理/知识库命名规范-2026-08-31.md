# The Memory 知识库命名规范

> [!abstract] 定位
> 本页是全库文件命名的唯一依据。服务于百万字自传体散文小说的智能体检索——
> **文件名即检索入口**，须同时满足：唯一可定位、自明可判断、稳定少变动。

---

## 一、总则

| 原则 | 含义 |
| --- | --- |
| **唯一性优先** | 文件名在全库范围内必须唯一。重名会导致 `[[wikilink]]` 指向歧义，是本库最严重的结构缺陷 |
| **自明性** | 不看路径也能判断文件内容与类别 |
| **最小改动** | 已合规的文件不动；只对违规项做收敛 |
| **稳定优先于优美** | 文件名变动成本高于正文。文学性体现在标题与正文，不体现在文件名 |

---

## 二、字符规则

### R1 分隔符
- 一律使用**半角连字符 `-`**。
- 例外一：人名内部的间隔号保留 `·`，如 `克里斯托弗·诺兰`、`丹尼尔·克雷格007`。
- 例外二：并列概念用 `·` 连接，如 `文学性·爽文性·细节性·准确性`。

### R2 括号
- 一律使用**全角中文括号 `（）`**，用于消歧、补充说明、状态限定。
- 例外：英文专有名词内部的半角括号保留，如 `CHENN（抖音博主）` 的括号实为中文全角，英文原名内部才用半角。

### R3 数字与编号
- 序列文件用**两位编号** `NN-`，同一序列内连续、不跳号。
- 编号与主题之间用 `-` 连接：`03-Q2-学校最美好的瞬间`。

---

## 三、日期规则

| 情形 | 格式 | 示例 |
| --- | --- | --- |
| 单点日期 | `YYYY-MM-DD` | `2026-08-31` |
| 跨月范围 | `YYYY-MM至YYYY-MM` | `2023-12至2026-02` |
| 跨年范围 | `YYYY至YYYY` | `2018至2024` |
| 日级范围 | `YYYY-MM-DD至YYYY-MM-DD` | `2026-05-21至2026-08-08` |

**区间内部一律用 `至`，不用 `-`**（避免与分隔符混淆）。

**位置规则**：

- **日期为序列主键**（同文件夹内按年代排列的一组文件）→ **年份前置**
  `2013至2019-小学时代背景`、`2024-高三备考与AI前夜场景素材稿`
- **日期为事件限定语**（单个素材、报告、审计）→ **日期后置**
  `邓稼先物理奖活动-2026-08-11`、`知识库总收录审计-2026-08-09`

## 四、分类命名规则

### C1 人物页
- 统一为**姓名**（不带任何前后缀）：`赵问竹`、`刘佑林`、`曾子沣`。
- 家庭关系页用**称谓**：`父亲`、`母亲`、`姑母（父亲的二姐）`、`表弟（何沛泽）`。
- **同名消歧**：用排数/班级后缀，全角括号：`彭议乐（第一排）`、`胡睿涵(G2212)` → 收敛为 `胡睿涵（G2212）`。
- **子档案同名页**：当某专题库内需建立与正典人物页同名的档案页时，必须加限定后缀，
  如 lover-best 影像库内的 `赵问竹（形象档案）`，以保证 `[[赵问竹]]` 唯一指向正典页。

### C2 索引页
- **域级入口**（一级目录）：`XXX索引` — `写作体系索引`、`文化与审美索引`、`高中阶段人物与素材索引`。
- **子库入口**（二级目录）：`XXX总索引` — `技法库总索引`、`收录审计总索引`、`00-人物审美库总索引`。
- **专项索引**：`XXX索引` — `文学阅读与自传写作索引`、`平行宇宙与梦境素材索引`。

### C3 素材页
`主题-补充说明-日期`，例如 `董佳好与刘佑林微信互动时间线-2024-05至2025-11`。

### C4 审计/报告页
`主题-审计/报告/核对-日期`，例如 `全库结构与完整性审计-2026-08-13`。

### C5 章节稿
`第X卷-主线（序号）关键场景`，例如 `第三卷-赵问竹线（一）答案·福袋·起哄`。

### C6 私密页
- 在文件名**末尾**统一追加 `（私密）`。
- 不使用 `（私密索引）`、`（附件原文）` 等变体。

### C7 禁用
- **禁止**把生成工具/模型名写入文件名（如 `GLM5.2-...`）——文件名应概括内容，不标注生产工具。
- **禁止**把临时状态写入文件名（如 `（已确认）`、`（学年待核）`）——状态归入 YAML 字段。

## 五、违规判定与处置

| 违规类型 | 判定 | 处置 |
| --- | --- | --- |
| **V1 重名冲突** | 全库存在相同 basename | 必须消解，加限定后缀 |
| **V2 括号不统一** | 使用半角 `()` 承担中文消歧 | 收敛为全角 `（）` |
| **V3 私密标记不一致** | 非 `（私密）` 的变体 | 统一为 `（私密）` |
| **V4 状态标记入文件名** | 含 `（已确认）` 等 | 移入 YAML，文件名删除 |
| **V5 日期位置/格式** | 违反 R3 | 按序列/事件二分归位 |
| **V6 工具名入文件名** | 含模型名/工具名 | 删除该段 |
| **V7 索引命名混乱** | 违反 C2 | 按域级/子库归位 |

---

## 六、执行纪律

1. 重命名**必须**同步更新全库 `[[wikilink]]`，否则产生断链。
2. 链接解析须正确处理 markdown 表格内的**转义竖线 `\|`**——它仍是目标/别名的分隔符。
3. 人名型空链接（毕业名录指向待建人物页）是**有意的结构性占位**，不得清理。
4. 每次批量重命名前，先在 `D:\The Memory\backups\` 生成时间戳快照。
