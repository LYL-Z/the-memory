# 荷马史诗：故事线与人物冲突索引

本页按二十四卷整理故事骨架。它用于查找结构位置，不替代原典阅读。人名采用常见中文译名；不同译本可能有异写。

## 一、《伊利亚特》二十四卷

| 卷 | 主要事件 | 冲突或结构功能 |
|---:|---|---|
| 1 | 阿波罗降下瘟疫。阿伽门农夺走布里塞伊斯。阿喀琉斯退出战斗。 | 私人荣誉冲突转成全军危机；开篇预告全部后果。 |
| 2 | 宙斯以梦误导阿伽门农。联军集结，出现舰船目录。 | 扩大世界规模；个人冲突被放入庞大联盟。 |
| 3 | 帕里斯与墨涅拉俄斯决斗。海伦在城墙上辨认希腊将领。 | 战争原因与现实战士并置；私人婚姻牵动城邦。 |
| 4 | 休战被破坏，战斗重启。 | 和平的脆弱性；神意与人的责任纠缠。 |
| 5 | 狄俄墨得斯大显身手，甚至伤及阿佛洛狄忒和阿瑞斯。 | 英雄高光也受神介入限制。 |
| 6 | 赫克托耳回城，与母亲、海伦、安德洛玛刻和儿子会面。 | 战争从战场落到家庭；预示城破与家人命运。 |
| 7 | 赫克托耳与大埃阿斯决斗，双方停战收尸。 | 敌手相互尊重；葬礼暂时中断暴力。 |
| 8 | 宙斯禁止诸神参战。特洛伊人把希腊人逼回船边。 | 阿喀琉斯缺席的集体后果加剧。 |
| 9 | 使团以礼物和劝说请求阿喀琉斯归队，他拒绝。 | 物质补偿无法立即修复受损尊严；嵌入墨勒阿格洛斯故事。 |
| 10 | 奥德修斯和狄俄墨得斯夜袭，杀死多隆并夺马。 | 黑夜、侦察和欺骗改变正面战斗节奏。 |
| 11 | 阿伽门农奋战后受伤，多名希腊主将退出。 | 危机逼近帕特罗克洛斯；代替者准备上场。 |
| 12 | 特洛伊人突破希腊营墙。 | 防线失效，退场者的影响具象化。 |
| 13 | 波塞冬暗中援助希腊人。 | 战局反复；神与人两条行动线交错。 |
| 14 | 赫拉诱使宙斯沉睡，希腊人短暂反击。 | 欲望与欺骗进入神界政治。 |
| 15 | 宙斯醒来，赫克托耳进攻船只。 | 危机抵达不可拖延的临界点。 |
| 16 | 帕特罗克洛斯穿阿喀琉斯盔甲参战，击退敌军后越界追击，被赫克托耳杀死。 | 替身结构；善意、荣耀冲动与过度推进共同制造死亡。 |
| 17 | 双方争夺帕特罗克洛斯的尸体和盔甲。 | 身体、名誉与记忆成为战斗对象。 |
| 18 | 阿喀琉斯得知死讯。忒提斯请赫淮斯托斯打造新盾。 | 愤怒改向；盾面把战争外的完整世界嵌入史诗。 |
| 19 | 阿喀琉斯与阿伽门农和解，重新武装。 | 制度性补偿完成，但死亡不可逆。 |
| 20 | 众神获准参战。阿喀琉斯重返战场。 | 人神两层冲突全面展开。 |
| 21 | 阿喀琉斯大肆杀戮，河神斯卡曼德反击。 | 英雄暴力逼近失控；自然不再只是背景。 |
| 22 | 赫克托耳独守城外，逃跑、回身决战，最终被阿喀琉斯杀死。 | 勇气与恐惧并存；胜利转为辱尸。 |
| 23 | 帕特罗克洛斯葬礼与竞技会。 | 共同仪式把失序竞争重新纳入规则。 |
| 24 | 普里阿摩斯赎回儿子遗体。阿喀琉斯与他共同哀悼。赫克托耳下葬。 | 愤怒在哀悼、交换、食物和停战中暂时结束。 |

### 主冲突链

`受辱 → 退出 → 同伴代战 → 同伴死亡 → 复仇 → 暴力越界 → 敌父来访 → 共同哀悼 → 归还遗体`

这条链最值得自传写作学习之处，不是“升级冲突”，而是每次选择都有后果。后果还会改变下一次选择的道德含义。

## 二、《奥德赛》二十四卷

| 卷 | 主要事件 | 冲突或结构功能 |
|---:|---|---|
| 1 | 诸神讨论返乡。雅典娜化身访客鼓励忒勒马科斯。 | 先写缺席者造成的空洞；从儿子视角建立父亲。 |
| 2 | 忒勒马科斯召开大会，秘密出航。 | 青年第一次公开行动；家内危机转向外部寻找。 |
| 3 | 在皮洛斯拜访涅斯托耳，听取战后返乡故事。 | 他人记忆拼出父辈世界。 |
| 4 | 在斯巴达拜访墨涅拉俄斯和海伦。求婚者策划伏击。 | 信息增加，危险同步增加；两条线并行。 |
| 5 | 众神命卡吕普索放人。奥德修斯造筏离岛，遇风暴。 | 正式让主人公进入现在时；自由以继续受难为代价。 |
| 6 | 瑙西卡在河边发现奥德修斯，教他进城求助。 | 陌生人如何获得安全与体面。 |
| 7 | 奥德修斯进入阿尔喀诺俄斯宫殿，获得接待承诺。 | 正面的待客范例。 |
| 8 | 宴会、竞赛与吟游诗。听到特洛伊故事后，奥德修斯落泪并准备自述。 | 公共歌谣触发私人记忆；听众变成讲述者。 |
| 9 | 奥德修斯开始回忆：奇科涅斯人、食莲者、独眼巨人。 | “无人”隐名救命，随后自报真名招来更久灾祸。 |
| 10 | 风袋、莱斯特律戈涅斯人、喀耳刻。 | 同伴失控、领导责任和诱惑反复出现。 |
| 11 | 前往冥府，咨询忒瑞西阿斯，并见母亲与旧日英雄。 | 返乡必须穿过死亡知识；英雄声名受到亡者经验修正。 |
| 12 | 塞壬、斯库拉与卡律布狄斯、太阳神牛群；全体同伴死亡。 | 知识不能消除代价；违禁与领导选择叠加。 |
| 13 | 费埃克斯人送他回伊萨卡。雅典娜把他变成乞丐。 | 地理返乡完成，社会返乡才开始。 |
| 14 | 奥德修斯投宿忠诚牧猪人欧迈俄斯，并讲虚假身世。 | 通过待客行为辨认盟友；假故事测试他人。 |
| 15 | 忒勒马科斯回岛，避开伏击。 | 父子两线即将汇合。 |
| 16 | 父子相认，制定对付求婚者的计划。 | 第一次关键辨认；身份秘密变成共同行动。 |
| 17 | 乞丐进入宫殿，受辱；老狗阿尔戈斯认出主人后死去。 | 最弱小的辨认者最先确认；克制替代即时反击。 |
| 18 | 奥德修斯击败乞丐伊鲁斯。佩涅洛佩向求婚者索取礼物。 | 伪装中的力量与策略；佩涅洛佩主动改变局面。 |
| 19 | 佩涅洛佩与“陌生人”长谈。欧律克勒娅凭伤疤认出奥德修斯。 | 语言保持含混，身体证据泄露身份。 |
| 20 | 预兆与最后准备。求婚者继续侮辱。 | 延迟爆发，积累伦理和行动条件。 |
| 21 | 佩涅洛佩设弓箭比赛。只有奥德修斯能张弓并穿过斧孔。 | 私人物件成为身份与能力测试。 |
| 22 | 奥德修斯、忒勒马科斯和盟友杀死求婚者，并处罚背叛者。 | 统治恢复，也留下集体暴力的伦理问题。 |
| 23 | 佩涅洛佩用婚床设试。奥德修斯说出秘密，夫妻相认。 | 共同建造且不可移动的物件，胜过外貌与口头宣告。 |
| 24 | 求婚者亡魂入冥府。奥德修斯与父亲拉厄耳忒斯相认。双方再战，雅典娜促成停战。 | 返乡延伸到父子三代与城邦；暴力循环被外力截断。 |

### 主结构链

`缺席造成失序 → 儿子寻找消息 → 主人公讲述旧难 → 地理返乡 → 伪装观察 → 分层辨认 → 物件验证 → 清除占有者 → 家庭与城邦重新承认身份`

## 三、可用于长篇目录设计的结构单元

| 荷马结构单元 | 作用 | 自传写作中的安全转译 |
|---|---|---|
| 使团劝返 | 同一事件由多人提出不同理由 | 让不同材料来源保留各自判断，不合成统一声音 |
| 嵌入故事 | 用旧故事解释当前选择 | 插入同期书信、日记或同伴回忆，并标明来源 |
| 目录与群像 | 让共同体获得规模 | 班级名录只作导航；有事件材料者才进入叙事 |
| 识别场景 | 用私人证据确认身份和关系 | 使用确有来源的旧物、称谓、共同经历，不编造“暗号” |
| 葬礼与宴食 | 让高冲突回到身体和社会仪式 | 写真实存在的收尾程序，不靠总结升华 |
| 返乡延迟 | 到达地点不等于完成心理变化 | 区分返校、回家等物理到达与关系恢复 |
