## 一、面部核心特征

### 脸型
- 偏长的鹅蛋脸，亦可呈圆脸观感（少年期与成年期造型差异）。颧骨线条干净柔和，下颌略收，侧颜鼻梁高挺。
- 轮廓线条清晰，骨骼感中等——不是凌厉的骨感，而是"能被看出形状"的清透骨相。
- 面部留白较多，属于"画布型"脸，能承载从少女到哥特的多重情绪。

### 眉眼
- **眉**：自然偏直的浅棕眉，弧度柔和，毛流感清晰；另有一组观察记录为"浓密有形、眉峰明显"，说明其眉形可随造型在野生与修饰间切换。
- **眼**：大而微挑，眼距略宽，虹膜呈**灰蓝 / 冰蓝 / 蓝绿**色（不同光线与妆造下呈现不同读数），是全脸最锐利的焦点。睫毛长但不上扬，下眼睑有自然卧蚕。
- **眼神特质**：专注、炽热、情绪饱满。可传递"被困住的精灵"（仰望镜头）、"被风拂过的玫瑰"（红毯）、"纽约下城少年感"（街拍）三种截然不同的状态。

### 鼻型
- 窄长，鼻尖略翘，鼻梁线条非常"利"——侧面轮廓的立体度主要由鼻梁支撑。
- 鼻型小巧，与偏长的脸型形成平衡。

### 唇形
- 薄至中等厚度，上唇微翘，唇线自然，放松状态下微微张开。
- 唇色偏冷玫瑰，常配哑光豆沙或正红；少年感造型时则近乎裸色。

### 皮肤与细节
- **冷白到瓷白**，红发衬托下更显通透，是典型的"冷白皮 + 暖调发色"的高对比组合。
- **标志性识别点：颧骨区与鼻梁的雀斑**。这是她最具辨识度的特征，也是粉丝所称的"招牌"。
- 另一组观察记录肤色"偏暖、透着日晒后的健康红晕"——说明其肤色随光线与妆造在冷白与健康暖白之间浮动。

### 辨识度核心
- **第一眼视觉焦点**：赤铜色长发与瓷白皮肤上的雀斑，二者构成的高对比度组合。
- **区别于他人的独有记忆点**：她是本库中**唯一以"雀斑"作为核心识别符号**的人物。这一点在写作中极具价值——雀斑意味着"没有被修正过的真实"，与精修无瑕的偶像美学形成对立。

## 二、气质与氛围感

### 核心气质标签
`#哥特玫瑰` `#冷白皮红发精灵` `#学院风与哥特切换器` `#新千年复古缪斯` `#脆弱的倔强`

### 气质复杂度
**混合气质，层次极丰富**。她的气质在两组对立之间摆荡，且每一组都能成立：

| 对立轴 | A 端 | B 端 |
|---|---|---|
| 温度 | 冷（瓷白肌肤、冰蓝眼瞳） | 热（赤铜发色、炽烈眼神） |
| 性别气质 | 少女（圆脸、卧蚕、连帽衫） | 少年（瘦长骨架、皮衣、中性姿态） |
| 强度 | 脆弱（湿发贴脸、微张的唇） | 倔强（下颌微收、抬眼直视） |
| 时间感 | 复古（八〇年代英伦朋克） | 当代（Y2K、纽约下城） |
| 场域 | 书卷（文学系女生、出版社编辑） | 街头（皮衣、牛仔、滑板感） |

这种"两端都能站住"的可变性，使她成为本库中**戏路最宽**的审美锚点。

### 情绪传递力
- 情绪基调：**沉静、倔、易碎**。静态画面自带叙事性——观者看到她会自动开始脑补她背后的故事。
- 故事感强度：**极强**。湿发造型时脆弱感倍增；仰望镜头时呈现"被困住"的叙事张力；红毯造型时则是"被风拂过的玫瑰"。
- 她不是"漂亮"，而是"有话要说"。

### 风格适配边界
- **最适配**：美式复古、哥特浪漫、学院风、Y2K、新千年怀旧、文艺片、成长叙事、奇幻（半精灵／女巫类）。
- **违和**：甜美公主风、成熟性感路线、极简商务风。强行甜化会破坏她最珍贵的"生涩的真实感"。

## 三、身形与体态

- **身形比例**：瘦长，肩线平直，骨架不宽但带有运动感的紧实线条。腰线明显，四肢偏细长。中等身高，视觉上偏修长。
- **体态特征**：脖颈修长，斜方肌不厚（这一点是"高贵感"与"紧张感"的分水岭，她属于前者）。站立时常带"头微仰、肩往后松"的造型意识，但不是僵硬的训练感，而是一种"我习惯被看，但我不迎合"的松弛。
- **视觉观感**：少年感与少女感并存。骨架撑得起皮衣，也撑得住缎面抹胸——这是她能横跨街头与红毯的物理基础。

## 四、造型适配度

### 发型适配
- **发色**：以**赤铜 / 焦糖 / 草莓铜**为标志色，亦可驾驭金棕与深红棕。**这是她审美体系的第一符号，不可替换。**
- **长度与卷度**：长发及胸为主。自然大卷（红毯）、湿发中分（BAFTA）、微卷中分 + 齐刘海（剧照）、直发 + 粉色雏菊发夹（首映）。
- **放大作用**：湿发贴脸 → 脆弱感倍增；大波浪 → 复古名伶；齐刘海微卷 → 少女与神秘并存；皮衣配自然卷 → 街头少年感。

### 妆容适配
- 底妆**哑光并刻意保留雀斑**——这是造型的灵魂，遮掉雀斑就等于抹掉她的辨识度。
- 唇色随场合在裸粉与正红之间切换；眼妆克制，多用内眼线 + 裸色眼影，不强调烟熏。
- **禁忌**：厚重修容、全哑光无瑕底妆、过度美瞳。

### 穿搭适配
- **红毯**：结构感抹胸（亮片、缎面、刺绣）+ 中性色（白、薄荷绿、棕、酒红）。
- **街拍**：黑色皮衣 + 白 T + 牛仔裤的"无装饰酷"；亦有奶白蕾丝 + 淡紫针织的柔化版本。
- **戏中**：连帽衫、夹克、工装，以朴素衬托角色的真实处境。
- **色彩体系**：赤铜 / 瓷白 / 冷蓝——三组色可独立成章，也可互相碰撞。
