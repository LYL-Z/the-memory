# 景甜

> 类型标签：智性清冷型 / 都市精英型 / 明艳贵气型 / 古典端庄 / 温婉大气 / 富贵花

## 一、面部核心特征

### 脸型
- 批次04：成熟的鹅蛋脸 / 长鹅蛋脸，面部纵向比例偏长，显得知性成熟。
- 批次06：鹅蛋脸偏瓜子，线条流畅，颧骨与下颌过渡自然。
- 批次08：鹅蛋脸，脸部线条柔和。
- 综合：脸型稳定在鹅蛋至长鹅蛋之间，头小脸小，骨相成熟，软组织分布均匀，属"越老越有味道"的类型。

### 眉眼
- 眉：批次04 记眉形精致、经专业修饰，眉峰位置恰当，既不凶也不柔，恰好的"有主见"感；批次06 记眉形修长、略带弧度，精致且利落，强调气场；批次08 记为柳叶眉，古典，眼妆柔和。
- 眼：眼型偏长，内外眼角清晰，双眼皮宽度适中。
  - 批次04：眼神温和但**有内容**——不是空灵的清澈，而是"我在认真看你/听你说"的专注感；笑起来眼角有自然纹路（鱼尾纹），增加真实感与亲和力。
  - 批次06：眼型细长上挑，双眼皮明显，眼神沉静而有距离感。
  - 批次08：眼型偏长，眼神温润。

### 鼻型
- 批次04：鼻梁挺直，鼻型端正，属"不出错也不抢镜"的标准美鼻。
- 批次06：鼻梁高挺，鼻头小巧，侧面线条立体。
- 批次08：鼻梁适中，鼻头圆润。

### 唇形
- 唇形优美，唇峰清晰。
- 批次04 为柔和玫瑰粉／豆沙色，强调"好气色"而非"性感"。
- 批次06 为红唇饱满，是整体妆容的视觉焦点之一。
- 批次08 唇形饱满、唇色自然，古装中偏豆沙或正红。

### 皮肤与细节
- 批次04：**发光的白皙**——在逆光／侧光的黄金时刻光线下，皮肤呈现出从内部透出的温润光泽。
- 批次06：瓷白、细腻、几乎无瑕疵，呈现高级光泽。
- 批次08：肤质细腻白皙。
- 综合：肤色白而匀，质感细腻，镜头下透光感强。

### 辨识度核心
- **第一眼视觉焦点**：温和但"有内容"的眼神，以及那份不急不缓的从容——她的脸不是一个表情，而是一段经历。
- **区别于他人的独有记忆点**：风格跨度极大而底子稳定。同为冷感美人，[[丽贝卡弗格森]] 是"地理性的、冰川式的冷"，而景甜是"阅历沉淀的、温和的成人冷"——她的冷从不刺人，只是让人不敢造次。

## 二、气质与氛围感

### 核心气质标签
- 独立、温和有力、都市、有故事。
- 雍容、冷静、自信、略带疏离的贵气。
- 温婉、沉稳、外柔内刚。
- 不是需要被保护的"小女孩"，也不是高高在上的"女王"，而是**有能力爱自己也有余力爱别人**的成年女性。

### 气质复杂度
- 混合气质，三副面孔可切换：
  1. **都市精英面**（批次04）：风衣、黄金时刻逆光、从容自信。
  2. **红毯贵气面**（批次06）：低盘发、红唇、丝绒与珍珠、压轴感。
  3. **古典端庄面**（批次08）：柳叶眉、低髻、华服、隐忍大气。
- 可变性强但内核统一——无论哪一面，都是"我很舒服地待在我自己的身体里"的自如感。

### 情绪传递力
- 静态画面传递的情绪基调：从容、温柔的力量、都市生活中的片刻安宁、经历过风雨之后的平静。
- 故事感强度高：读者会觉得这个角色背后一定有很多经历。
- 适合承载：放下、成全、隐忍后的爆发、成年人的体面告别。

### 风格适配边界
- **最适配**：职场剧中的女性领袖（但不霸道）、男主角"懂他的"成熟伴侣或前任、独立经营人生的都市女性、世家千金、成熟女明星、神秘贵妇、掌控局面的女二号、古装名门闺秀、隐忍复仇的王妃／皇后。
- **违和**：青春期校园甜妹、需要"破碎感／易碎感"的角色、暗黑颓废系女主。

## 三、身形与体态

- **身形比例**：高挑，观感约 168 cm，身形苗条但不干瘪；骨架适中；头小脸小。
- **体态特征**：
  - 批次04：双手插兜（松弛自信）、侧面抬手遮阳／挡嘴（生动自然）、正面微笑（温暖大方）；体态舒展，肩背挺拔但不僵硬。
  - 批次06：肩颈线条优美，锁骨分明；体态端庄挺直，适合大场面。
  - 批次08：身材匀称，骨架适中，坐姿站姿都透着教养与稳重。
- **视觉观感**：舒展而不松懈，端庄而不紧绷——一种被良好生活与自我要求共同塑造出的身形语言。

## 四、造型适配度

- **发型适配**：
  - 都市面：深棕（偏暖调）中长发，低马尾或低丸子头，头顶与两侧留适量碎发和刘海修饰脸型，几缕发丝被风吹起。
  - 红毯面：浓黑发色，中长发／盘发，低盘发、侧分波浪，强调露肩颈线。
  - 古装面：乌黑长发，低髻、盘发，发丝服帖有光泽。
  - 造型哲学：介于"随意"与"精心打理过"之间的微妙平衡点——这正是高级感的来源。
- **妆容适配**：精致通勤妆——完美无瑕的底妆、精细眉毛、强调眼线与睫毛、腮红打在苹果肌，唇色为低饱和玫瑰／豆沙；红毯可切换正红或浆果色唇妆、精致眼线、珠光眼影，配珍珠配饰，强调"盛装出席"的仪式感。
- **穿搭适配**：
  - 都市面：卡其色／米色经典 trench coat（双排扣、肩章、腰带、袖口绑带齐全），质地优良，选它就等于选择"我有品位但不会用力过猛"。
  - 红毯面：酒红、墨绿、珍珠白、黑色丝绒等高饱和或华贵色的高定礼服、复古港风。
  - 古装面：红金配色华服。
  - 光线：批次04 全部采用黄金时刻逆光／侧逆光，发丝边缘镶金边，面部有伦勃朗光效果，电影感极强。
