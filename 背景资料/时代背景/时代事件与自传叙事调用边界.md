# 时代事件与自传叙事调用边界

## 一、四级证据模型

### A级：个人直接材料

包括当时形成的书信、日记、聊天原始记录、照片、票证、课程表、作业、录取材料和用户明确确认的亲历事实。A级材料可支持“我做了什么、在哪里、与谁一起”的叙述，但仍不能自动进入他人内心。

### B级：个人回忆或他人回忆

包括刘佑林事后回忆、同学手稿、教师评语和家人转述。可写成“我记得”“在某人的回忆里”“老师当时概括我”，不能伪装成客观全知事实。若记忆与原始材料冲突，先保留冲突。

### C级：学校与地方背景

包括学校官网、教育部门文件、招生政策、课程方案和校园公开报道。可说明“当时学校或地区采用何种制度”，不能证明刘佑林实际经历了文件中的每一项安排。

### D级：全国与世界背景

包括疫情、战争、奥运、航天和生成式AI等公共事件。D级材料只提供时代坐标。若个人材料没有回应，不得写成“这件事改变了我”。

## 二、从公共事件进入个人叙事的条件

一个公共事件要进入正文，至少满足以下一项：

1. 改变了个人日程，例如停课、延期、返校、考试或出行；
2. 出现在个人交流中，例如聊天、课堂讨论、作业或新闻摘录；
3. 改变了物质环境，例如口罩、健康码、线上课堂或AI工具；
4. 与后来选择形成可证实联系，例如强基计划与2025年录取；
5. 成为明确的时间锚点，例如“北京冬奥会开幕那周”，且个人材料能确认该时间关联。

若五项均不满足，事件只能留在背景笔记，不进入个人章节。

## 三、叙述强度控制

| 可用表述 | 证据要求 | 不可自动升级为 |
|---|---|---|
| “2020年春季，长沙学校开展线上教学” | 教育部门或地方文件 | “我每天在卧室用某设备上课” |
| “湖南于2021年实施新高考” | 省级考试文件 | “新高考让我选择物化生” |
| “2022年俄乌战争进入全球新闻议程” | 联合国等公共资料 | “我由此形成某种政治立场” |
| “2023年生成式AI进入教育讨论” | UNESCO及教育资料 | “我从此精通AI开发” |
| “强基计划2020年启动” | 教育部文件 | “我从初中就决定报考强基” |

## 四、疫情叙事的特别规则

1. 区分疫情发生、学校安排与个人体验。
2. 不补造感染、隔离、核酸、家庭损失或心理创伤。
3. “停课不停学”不等于每所学校、每个年级同步讲授完全相同的新课。
4. 2023年WHO结束国际紧急状态，不等于疫情在某一天彻底结束。
5. 若写线上课堂，设备、房间、家人在场情况和课堂状态必须来自个人材料。

## 五、学校层级与竞争格局的特别规则

1. “长沙四大名校”是社会和媒体俗称，不是法定行政等级。
2. 2025年指标生三类分组是具体招生操作口径，不能倒推至2019年以前。
3. 学校规模、荣誉、升学结果和课程特色若来自校方宣传，应写成“校方公开资料称”。
4. 刘佑林未就读的长郡、雅礼、长沙市一中、湖南师大附中和南雅，只能作为区域比较背景；不得写成个人校园经历。
5. 学校整体声誉不能推断某位学生的能力、家庭或人格。

## 六、全国与世界事件的特别规则

### 战争和国际政治

只写可核实的事件、日期、机构决议和公开影响。不能把宿舍谈话或“喜欢时政”的同伴印象扩写为固定政治立场。涉及争议议题时，区分事实、观点和当事人当时的理解。

### 体育赛事

奥运会可作年代与季节锚点。没有观看记录时，不补写比赛细节、情绪或同伴讨论。

### 航天与科技

航天成就可说明理科教育所处的社会传播环境，但不能直接解释专业选择。AI工具的使用也不等于理解其模型原理，更不等于完成独立模型训练。

## 七、双视角写法

### 亲历的我

只知道当时能够知道的事。不能用2026年的政策知识、人物结局和关系解释提前替代当时感受。

### 回望的我

可以补充公共背景、制度解释和后来理解，但要有提示，例如：

- “多年以后我才知道……”
- “那时我并不理解，这项安排属于……”
- “从后来查到的文件看……”

回望不是纠正一切，也不是替过去的自己辩护。它负责标出认知差异。

## 八、推荐段落结构

1. 先写可确认的个人场景；
2. 再用一到两句交代公共背景；
3. 回到人物动作或选择；
4. 若无个人反应证据，以留白结束，不强行升华。

示例结构：

> 学校通知改变了返校日期。后来查文件才知道，那不是一所学校的临时决定，而是疫情应急教学的一部分。至于我当时究竟是庆幸还是烦躁，留下的材料没有说，我也不准备替那个年纪的自己回答。

## 九、公开导出规则

公共背景可以进入公开稿，但必须排除：

- `私人资料`目录中的原文、证件和联系方式；
- 未经当事人同意的感情、健康与家庭信息；
- 对第三方动机、阶层和人格的推测；
- 未核出处的网络语句与图片。

公共来源链接可保留。学校与政府资料若发生更新，应标注访问日期，避免把当前状态倒写为历史状态。
