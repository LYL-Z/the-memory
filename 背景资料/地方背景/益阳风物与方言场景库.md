# 益阳风物与方言场景库

> 本页为卷一（童年与底色）、卷二（青春与阵痛）提供可核证的城市场景底色：地理风物、方言称谓、童谣语料。所有事实来自政府官网与公开百科，不补造未确认的个人互动。

## 一、城市风物场景（资江两岸）

| 风物 | 位置/说明 | 叙事价值 |
|---|---|---|
| **资江** | 益阳母亲河，南北穿城；"过江"可作资阳童年与赫山新家的时代性过渡意象 | 空间张力主线 |
| **大码头** | 资江北岸十五里麻石街起点，益阳老城商贸核心；实验小学即在大码头街道新石路21号 | 老城烟火、麻石街质感 |
| **麻石街** | 资江北岸十五里麻石老街，明清古巷肌理（始建于 1551 年前后） | 童年步行空间 |
| **白鹿寺** | 资江南岸，唐元和年间广慧建，益阳最古佛寺之一 | 宗教/年节氛围 |
| **会龙山** | 资江南岸丘陵，裴公亭所在；实验小学毗邻 | 家庭出游、地形质感 |
| **裴公亭** | 会龙山上，纪念裴休；与白鹿寺、资江构成南岸景观带 | 凭吊/远眺场景 |
| **学门口文庙** | 资阳老城文庙遗址区 | 科举/文教记忆 |
| **秀峰公园** | 赫山区金银山，1988 年建成约 600 亩、湖面 310 余亩，无围墙免门票 | 刘佑林家（人大旁）童年玩耍地 |
| **安化梅城十里牌村** | 安化南部山区，奶奶家；1072 年建县至 1951 年为安化县治 | 春节回乡、祖辈场景 |
| **"银城"称谓** | 益阳别称（银城），因历史上银楼/商贸繁荣 | 城市自称底色 |

> 场景调用：资阳老家（麻石街/大码头/资江）与赫山新家（秀峰公园人大旁/铂悦府）构成"老城—新区"双地理质感，写作时须区分，不得混写（见 [[益阳与安化地方背景#四、个人叙事边界]]）。

## 三、童谣与民间语料（候选）

- **《月亮粑粑 狗咬嗲嗲》**：益阳经典童谣，"月亮粑粑，肚里坐个嗲嗲，嗲嗲出来买菜……"句式，可作卷一童年听觉底色。
- **《点子点菠萝》**：益阳儿童点数游戏歌谣。
- **《大码头的早晨》**：本土生活场景谣，与大码头麻石街意象相连。
- **《推谷几》**：农事/生活童谣。
- 益阳本土戏曲：**弹词、地花鼓、围鼓**（官方列为濒危，保护不足）——可作"被遗忘的乡土文化"叙事线索。

> 童谣原文以公开流传版本为准，写作引用时保留方言用字（嗲嗲/菠/谷几），不改写为普通话。

## 四、叙事调用边界

- 本页为**公开场景库**，不写刘家与具体地点的互动（除非口述/凭证，见 [[益阳与安化地方背景]] 五处已确认地点）。
- 方言称谓用于对话/内心独白时，首次出现建议括注普通话，避免读者误解（如"爷（爸爸）"）。
- 风物与童谣是"底色"不是"情节"，不得脱离人物硬塞。
