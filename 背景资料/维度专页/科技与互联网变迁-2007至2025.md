## 二、时代质感意象库（跨代物质生活质感）

- **终端**：诺基亚直板/翻盖功能机 → 山寨机（双卡双待、跑马灯）→ iPhone/安卓智能机 → 全面屏。触感从九宫格物理键到玻璃屏。
- **上网场所**：黑网吧（烟味、CRT 显示器、拨号/ADSL）→ 宿舍 WiFi → 手机随时在线。2G 文字慢刷 → 3G 能看图 → 4G 秒开视频 → 5G 直播无延迟。
- **支付**：纸币硬币 → 公交卡/校园卡 → 支付宝扫码 → 微信红包 → 收款码贴满摊贩。
- **视听**：MP3/MP4 拷贝歌曲 → 优酷/土豆看剧 → B 站二次元 → 抖音/快手刷短视频；从"下载到本地"到"无限流"。
- **游戏**：单机/小游戏 → 网吧 CF/LOL → 手游《王者荣耀》(2015) 开黑 → 《原神》(2020) 跨端。
- **社交**：QQ 空间/留言板 → 微博围观公共事件 → 微信朋友圈私密圈层 → 短视频博主粉丝经济。
- **防疫器物**：口罩（2020 起常备）、绿/黄/红健康码、行程卡截图、核酸亭、场所码。
- **AI 侵入**：2023 起"大模型"成口头禅；写作/作业/办公接入对话式 AI；2025 DeepSeek 让本地推理平民化。
